# ORBITA — اصلاح نهایی شناسنامه کشورها در پوسته روشن

## هدف
رفع مشکل خوانایی عنوان دسته‌ها در پنل آماری تیرهٔ شناسنامه کشورها، هنگام استفاده از پوسته روشن.

## تغییر دقیق
- برچسب متنی زیر اعداد در ۱۴ کارت آماری، فقط در پوسته روشن سفید می‌شود.
- رنگ اعداد و شاخص‌های عددی حفظ می‌شود.
- رنگ آیکون‌ها و عنوان طلایی پنل تغییر نمی‌کند.
- پوسته تاریک هیچ تغییری نمی‌کند.
- نوشته‌های سایر بخش‌های شناسنامه که روی زمینه روشن قرار دارند تیره باقی می‌مانند تا کنتراست و خوانایی آن‌ها حفظ شود.
- قانون CSS مربوط به متن توضیحی قدیمی حذف شده است؛ خود متن قبلاً از HTML شناسنامه حذف شده بود و در JavaScript نسخه مبنا وجود ندارد.

## فایل‌های لازم برای جایگزینی
فقط دو فایل:
1. `assets/css/app.css`
2. `index.html`

فایل JavaScript، داده‌ها، لوگوها و سایر دارایی‌ها تغییر نکرده‌اند.

## نصب
1. در مخزن GitHub، از دو فایل فعلی نسخه پشتیبان بگیر.
2. دو فایل هم‌مسیر داخل این بسته را جایگزین کن.
3. Commit کن و منتظر Deploy در Render بمان.
4. پس از Deploy، صفحه را با Hard Refresh باز کن و شناسنامه یک کشور را در پوسته روشن بررسی کن.
5. پوسته تاریک را نیز کنترل کن تا اطمینان حاصل شود ظاهر آن تغییری نکرده است.

نیازی به اجرای ترمینال VS Code نیست.

## نکته درباره نسخه مبنا
این بسته بر اساس بستهٔ گام چهارم لوگوهای سازندگان ماهواره و قطعات ساخته شده است. قابلیت‌های گام‌های قبلی، از جمله حذف متن توضیحی قدیمی، در نسخه مبنا حفظ شده‌اند. اگر نسخهٔ فعلی مخزن با بستهٔ گام چهارم تفاوت دارد، قبل از جایگزینی فایل‌ها تفاوت‌ها را بررسی کن.

## نسخه و کش
فقط نسخهٔ CSS به‌روزرسانی شده است. نسخه‌های داده و JavaScript تغییر نکرده‌اند تا بارگذاری مجدد غیرضروری داده‌ها ایجاد نشود.

## وضعیت انتشار
بسته آمادهٔ بارگذاری است؛ هنوز Commit، Push یا Deploy انجام نشده است.

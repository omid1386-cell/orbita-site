# ORBITA — گام چهارم: درج اعتبار توسعه‌دهنده در صفحه آغازین

## تغییر نهایی
عبارت انگلیسی زیر، با همان نگارش، در پایین صفحه آغازین/لودینگ رَسپهر اضافه شده است:

**Produced by Omidreza Safar**

این عبارت فقط در بخش `#raspehrSplash` وجود دارد و پس از ورود کاربر به نقشه، همراه با صفحه آغازین حذف می‌شود.

## دامنه تغییر
- فقط فایل `index.html` تغییر کرده است.
- عبارت در پایین صفحه آغازین، مستقل از محتوای مرکزی و با اندازه ظریف قرار گرفته است.
- رنگ و اندازه متن کم‌تأکید است و با هویت بصری فعلی صفحه تداخل ایجاد نمی‌کند.
- فاصله پایین با safe-area موبایل سازگار است.
- تنظیم `prefers-reduced-motion` رعایت شده است.

## مواردی که دست‌نخورده مانده‌اند
- `assets/js/app.js` و اصلاحات عملکرد زوم گام سوم
- `assets/js/raspehr-splash.js` و منطق نمایش/حذف صفحه آغازین
- لوگوی اصلی اسپاش
- نام و هویت بصری رَسپهر
- نقشه، داده‌ها، مختصات، شرکت‌ها، شناسنامه‌ها و لایه‌ها
- نسخه‌های کش اسکریپت و داده‌ها

## روش نصب
۱. از `index.html` فعلی مخزن نسخه پشتیبان بگیر.
۲. فایل `index.html` داخل این بسته را در ریشه مخزن جایگزین کن.
۳. تغییر را Commit و Push کن تا Render نسخه جدید را منتشر کند.
۴. پس از Deploy، سایت را با Hard Refresh باز کن.
۵. بررسی کن عبارت فقط هنگام نمایش صفحه آغازین دیده شود و در نمای اصلی نقشه وجود نداشته باشد.

**هیچ فایل دیگری را برای این گام جایگزین نکن.**

## آزمون
آزمون اختصاصی کنترل می‌کند که:
- عبارت دقیقاً یک بار وجود داشته باشد؛
- فقط داخل صفحه آغازین باشد؛
- پایین صفحه قرار بگیرد؛
- تنظیمات دسترس‌پذیری و نسخه‌های گام سوم حفظ شوند.

## وضعیت انتشار
فایل اصلاح‌شده و بسته آماده بارگذاری است. هیچ Commit، Push یا Deploy انجام نشده است.

# ORBITA — اصلاح نهایی فونت و چیدمان اعتبار صفحه آغازین

## تغییرات
- فونت اعتبار `Developed by Omidreza Saffar` به فونت اصلی اپ (`Dana`) تغییر کرد.
- اندازه دسکتاپ به ۱۳ تا ۱۴ پیکسل و موبایل به ۱۳ پیکسل کاهش یافت.
- وزن نوشته به ۵۰۰ تنظیم شد تا با تایپوگرافی رابط هماهنگ باشد.
- ارتفاع پنل پایین در دسکتاپ به ۱۰۴ و در موبایل به ۸۸ پیکسل کاهش یافت.
- فضای رزروشده پایین محتوای صفحه آغازین متناسب با پنل جدید اصلاح شد.
- خط جداکننده، رنگ طلایی، پس‌زمینه سرمه‌ای، گوشه‌های گرد و متن حفظ شدند.

## فایل‌های لازم برای بارگذاری
۱. `index.html` — در ریشه مخزن GitHub جایگزین شود.

فایل `assets/css/app.css` در بسته فقط برای مرجع و حفظ نسخه قبلی قرار گرفته و در این مرحله تغییر نکرده است؛ برای این اصلاح لازم نیست دوباره آن را بارگذاری کنی.

## پاک‌سازی اختیاری
فایل فونت قبلی `assets/fonts/ComicNeue-Bold.woff2` دیگر در صفحه استفاده نمی‌شود. باقی ماندنش مشکلی ایجاد نمی‌کند، اما برای تمیز ماندن مخزن می‌توانی آن را از GitHub حذف کنی.

## انتشار
فایل جدید `index.html` را Commit و Push کن و پس از Deploy در Render، صفحه آغازین را یک‌بار با Hard Refresh باز کن. نیازی به اجرای دستور در ترمینال نیست.

# ORBITA — اصلاح نهایی خوانایی شناسنامه کشورها در پوسته روشن

## علت مشکل قبلی
اصلاح قبلی فقط یک برچسب آماری را هدف می‌گرفت و به‌علاوه، اگر فایل CSS جدید در مخزن جایگزین نشده باشد، تغییر index به‌تنهایی رنگ‌ها را اصلاح نمی‌کند. این بسته هر دو فایل لازم را با هم به‌روزرسانی می‌کند و شناسه کش CSS را نیز تغییر می‌دهد تا مرورگر فایل جدید را دریافت کند.

## اصلاحات
- تمام عنوان‌های ۱۴ کارت آماری در پنل تیره شناسنامه، سفید و خواناتر می‌شوند.
- اندازه برچسب‌های زیر اعداد از ۹ به ۱۰ پیکسل افزایش یافته و وزن فونت تقویت شده است.
- رنگ اعداد هر دسته همچنان از `--country-category-color` گرفته می‌شود و تغییر نمی‌کند.
- رنگ عنوان طلایی پنل حفظ می‌شود.
- نشان «تعداد رکوردهای ثبت‌شده» در سربرگ شناسنامه در پوسته روشن رنگ تیره و پس‌زمینه روشنِ دارای کنتراست می‌گیرد.
- رنگ متن تب‌ها، نام، موقعیت، توضیحات، برچسب دسته‌ها، لینک‌ها و پیام خالی هر دسته در پوسته روشن صریح و خوانا می‌شود.
- هیچ قانون جدیدی برای پوسته تاریک اضافه نشده است.

## فایل‌های لازم برای جایگزینی
فقط این دو فایل را در مسیرهای دقیق خود جایگزین کن:
1. `assets/css/app.css`
2. `index.html`

**هر دو فایل باید بارگذاری شوند.** جایگزینی index به‌تنهایی کافی نیست.

## حفظ قابلیت‌های قبلی
نسخه فعلی index همچنان این موارد را حفظ می‌کند:
- بهینه‌سازی زوم نقشه و پایداری نشانگرها (گام سوم)
- لوگوهای سازندگان ماهواره و قطعات
- اعلان فرود بعدی
- قابلیت بزرگ‌نمایی لوگوها
- اعتبار توسعه‌دهنده در صفحه آغازین: `Produced by Omidreza Safar`

فایل JavaScript و داده‌ها در این بسته تغییر نکرده‌اند.

## نصب
1. از دو فایل فعلی GitHub نسخه پشتیبان بگیر.
2. فایل `assets/css/app.css` داخل بسته را در همان مسیر مخزن جایگزین کن.
3. فایل `index.html` داخل بسته را در ریشه مخزن جایگزین کن.
4. هر دو را با هم Commit و Push کن.
5. پس از پایان Deploy در Render، سایت را با Hard Refresh باز کن؛ در صورت لزوم یک بار کش مرورگر را پاک کن.
6. پوسته روشن را فعال کن و شناسنامه ایران و یک کشور دیگر را باز کن.
7. رنگ و خوانایی متن کارت‌ها، نشان تعداد رکورد، تب‌ها و توضیحات را بررسی کن.
8. پوسته تاریک را هم کنترل کن تا مطمئن شوی ظاهر قبلی آن حفظ شده است.

نیازی به اجرای ترمینال VS Code نیست.

## وضعیت
بسته آماده بارگذاری است. هنوز GitHub، Render یا سایت زنده تغییر داده نشده است.

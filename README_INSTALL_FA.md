# ORBITA — تغییر صرفاً فونت اعتبار صفحه آغازین

## مرجع
فونت عبارت `Developed by Omidreza Saffar` مطابق تصویر مرجع دوم به یک قلم دست‌نویسِ غیرمتصل و خوانا تغییر داده شده است. برای نمایش یکسان در موبایل و دسکتاپ، فونت Comic Neue به‌صورت محلی در پروژه قرار گرفته و از فونت سیستم عامل وابسته نیست.

## دقیقاً چه چیزی تغییر کرده؟
- فقط خانواده فونت عبارت اعتبار تغییر کرده است.
- فونت به‌صورت فایل محلی `assets/fonts/ComicNeue-Bold.woff2` بسته‌بندی شده است.
- فونت در صفحه آغازین preload می‌شود تا زودتر بارگذاری شود.

## چه چیزهایی عمداً تغییر نکرده‌اند؟
- متن دقیق: `Developed by Omidreza Saffar`
- رنگ طلایی
- اندازه فونت در دسکتاپ و موبایل
- جایگاه، فاصله‌ها و وزن CSS
- پنل سرمه‌ای، گوشه‌های گرد و خط جداکننده
- سایر عناصر صفحه آغازین
- اصلاح پوسته روشن شناسنامه کشورها، نقشه و لوگوها

## فایل‌هایی که باید در GitHub قرار بگیرند
۱. `index.html` — جایگزین فایل فعلی در ریشه مخزن.
۲. `assets/fonts/ComicNeue-Bold.woff2` — فایل فونت جدید؛ این مسیر را ایجاد کن اگر وجود ندارد.

فایل `assets/css/app.css` در بسته فقط برای حفظ نسخه قبلی قرار گرفته و در این تغییر دست‌نخورده است؛ لازم نیست دوباره جایگزینش کنی، مگر اینکه بخواهی نسخه بسته را به‌صورت کامل همگام کنی.

## انتشار
پس از Commit و Push، منتظر Deploy در Render بمان. برای این مرحله نیازی به اجرای ترمینال نیست.

## مجوز فونت
Comic Neue تحت SIL Open Font License 1.1 منتشر شده است. متن مجوز و انتساب سازندگان در `assets/fonts/OFL-1.1.txt` قرار دارد.

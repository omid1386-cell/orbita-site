# اصلاح نام فارسی کشور در شناسنامه ORBITA

## علت اینکه تغییر قبلی دیده نشد
نام شناسنامه هنگام کلیک روی چندضلعی کشور از داده‌های لایه جغرافیایی نقشه (`NAME_FA`) دریافت می‌شود، نه فقط از `data/sites.json`. بنابراین تغییر `country_fa` در رکورد پایگاه پالماخیم به‌تنهایی عنوان شناسنامه کشور را تغییر نمی‌داد.

## اصلاح انجام‌شده
- در رابط فارسی، عنوان شناسنامه برای کشور با نام canonical انگلیسی `Israel` یا کد ISO `IL` / `ISR` به «فلسطین اشغالی» نمایش داده می‌شود.
- نام canonical انگلیسی و شناسه/کد کشور در منطق داخلی دست‌نخورده می‌ماند.
- مقدار فارسی خامی که برای تطبیق رکوردهای شرکت‌ها و پایگاه‌ها استفاده می‌شود جدا نگه داشته شده است؛ بنابراین تغییر عنوان نباید باعث ناپدیدشدن رکوردهای منتسب به این کشور یا تغییر شمارش‌ها شود.
- در رابط فارسی، زیرعنوان انگلیسی `Israel` از زیر عنوان فارسی حذف می‌شود تا نام درخواستی به‌صورت یکدست دیده شود.
- در رابط انگلیسی، عنوان `Israel` حفظ می‌شود. رابط عربی نیز تغییری نمی‌کند.

## نصب پیشنهادی (Patch)
از ریشه مخزن Git و پس از گرفتن backup از `assets/js/app.js` اجرا کنید:

```bash
git apply --check COUNTRY_NAME_FA_DISPLAY_FIX.patch
```

اگر دستور بالا بدون خطا تمام شد:

```bash
git apply COUNTRY_NAME_FA_DISPLAY_FIX.patch
```

سپس:

```bash
node --check assets/js/app.js
node tests/israel_fa_display.test.cjs
```

فایل patch فقط `assets/js/app.js` را تغییر می‌دهد. هیچ فایل داده، شناسه، مختصات، پرچم یا تصویر را تغییر نمی‌دهد.

## اگر patch قابل اعمال نبود
به معنی تفاوت نسخه فعلی `assets/js/app.js` با نسخه مبنای این patch است. در این حالت patch را به اجبار اعمال نکنید و فایل فعلی `assets/js/app.js` را برای ادغام دقیق ارسال کنید. از جایگزینی کامل فایل با نسخه داخل بسته خودداری کنید، چون ممکن است تغییرات جدیدتر سایت را بازنویسی کند.

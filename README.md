2. تغییرات را با Git بررسی و سپس commit/push کنید؛ یا فایل‌های استخراج‌شده را از رابط GitHub با مسیرهای متناظر بارگذاری کنید.
3. برای اجرای تست‌ها در ریشهٔ پروژه:

   ```sh
   node --check assets/js/app.js
   for test in tests/*.test.cjs; do node "$test" || exit 1; done
   ```

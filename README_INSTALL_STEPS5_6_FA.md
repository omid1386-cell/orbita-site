# راهنمای اعمال گام‌های ۵ و ۶ رسهپه

بسته `ORBITA_Steps5_6_CUMULATIVE_2026-11-21.zip` شامل همه فایل‌های لازم **گام‌های ۱ تا ۶** است. اگر گام‌های ۱ تا ۴ را هنوز منتشر نکرده‌اید، بسته تجمیعی را مستقیماً از ریشه مخزن GitHub مطابق مسیر فایل‌ها آپلود کنید. اگر گام‌های ۱ تا ۴ نصب شده‌اند، از بسته `ORBITA_Steps5_6_DELTA_2026-11-21.zip` که فقط فایل‌های تغییرکرده در گام‌های ۵ و ۶ را دارد استفاده کنید.

۱. پیش از هر آپلود از وضعیت فعلی مخزن و `index.html` نسخه پشتیبان بگیرید.
۲. فایل‌ها را در همان مسیر نسبی نوشته‌شده داخل ZIP جایگزین/اضافه کنید. نیازی به تغییر `assets/js/app.js` و `data/upcoming_landings.json` نیست.
۳. محلی یا در Actions آزمون‌ها را اجرا کنید:

```bash
python -m unittest discover -s tools -p 'test_global_landings.py' -v
node tests/upcoming-landing-filters.test.cjs
node tests/upcoming-landing-ui.test.cjs
node tests/upcoming-launch-filters.test.cjs
node tests/upcoming-launch-ui.test.cjs
node tests/upcoming_landings.test.cjs
```

۴. در GitHub Actions گردش‌کار `refresh-global-landings-120-days` را به‌صورت دستی اجرا کنید. **در اولین اجرا ممکن است API، صفحه‌بندی یا محدودیت دسترسی، خطا بدهد**؛ در این صورت فایل خروجی قدیمی/خالی باقی می‌ماند. محدودیت و عدم کامل‌بودن پوشش جهانی در رابط ذکر می‌شود.
۵. در برنامه، «فرودهای پیش‌رو» را باز کنید و ۷/۱۴/۳۰/۱۲۰ روز، یک کشور و ترکیب چند کشور را بررسی کنید. سپس هر دو حالت مبنای کشور و پیام نبود داده را بیازمایید.
۶. هیچ‌یک از تغییرات این بسته از طرف ChatGPT در GitHub یا Render منتشر نشده‌اند.

نکته: تا پیش از گام ۷ لازم است موقعیت، ظاهر آیکون‌ها، پنل و فیلترها طبق بازخورد ثبت‌شده بازطراحی شوند.

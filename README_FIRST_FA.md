# نصب سریع ORBITA — حذف ۴ رکورد + متن سفید ۱۰٫۵ پیکسل

**این نسخه جایگزین بسته اصلاحات هویت و فونت قبلی است. بسته قبلی را جداگانه نصب نکنید.**

۱. ابتدا از GitHub یک شاخه پشتیبان بسازید یا ZIP نسخه فعلی را دانلود کنید. این بسته برای سایت نقشه جهانی است و باید روی همان نسخه‌ای که بسته نقشه جامع روی آن نصب شده، قرار گیرد.
۲. ZIP را Extract کنید؛ **خود فایل ZIP را داخل مخزن بارگذاری نکنید**.
۳. فایل `index.html` را در ریشه مخزن و فایل‌های `assets/css/app.css`، `assets/js/app.js`، `data/companies.json` و `data/companies_propulsion.json` را دقیقاً در مسیر همنام آپلود/جایگزین کنید.
۴. فایل‌های `tests/` را در همان پوشه موجود ادغام کنید. پرونده‌های `docs/` و `reports/` برای سابقه و کنترل کیفیت‌اند؛ آن‌ها را می‌توان در مسیر همنام نگه داشت.
۵. پس از انتشار، صفحه را با Refresh سخت یا مرورگر ناشناس باز کنید؛ روی یک شرکت پیشرانش که تاریخچه دارد بزنید و خوانایی هر دو کارت را در فارسی و انگلیسی و در موبایل بررسی کنید.
۶. اگر بعد از بسته جامع نقشه جهانی، در فایل‌های بالا تغییرات مستقل داده‌اید، **به‌جای جایگزینی مستقیم، ابتدا اختلاف‌ها را تطبیق دهید**؛ خصوصاً `companies.json` و `app.js`.

## نتیجه مورد انتظار

- هیچ‌یک از شناسه‌های `sharif-iran`, `avio-aero`, `ion-satellite`, `cubestar` در داده عمومی نقشه وجود ندارد.
- متن محتوای دو کارت تاریخچه پیشرانش **سفید (#fff)** و با اندازه **۱۰٫۵px** نمایش داده می‌شود؛ عنوان‌ها طلایی/سبز باقی می‌مانند.
- شمار کل شرکت‌ها ۲۶۶ و عضویت پیشرانش ۶۸ خواهد بود؛ سایر دسته‌ها همان مقدار پیشین را حفظ می‌کنند.
- شماره نسخه CSS در `index.html` برای رفع کش افزایش یافته است.

برای جزئیات گزارش `REPORT_FA.md` را ببینید.

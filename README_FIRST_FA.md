# شروع نصب بسته بازسازی عمیق شرکت‌های پرتاب ORBITA

## دقیقاً چه چیزی داخل این بسته است؟
این بسته فقط بخش **شرکت‌های پرتاب در نقشه جهانی** را به‌روزرسانی می‌کند. داده‌ها و رابط‌های ۱۶٬۰۲۱ ماهواره و پروژه‌های فضایی وارد بسته نشده‌اند. تعداد واقعی پرونده‌های شرکت پرتاب در ورک‌اسپیس مبنا **۶۸** است، نه ۸۸. برای ۲۰ پرونده فرضیِ دیگر، شناسه و داده‌ای در این نسخه وجود ندارد و رکوردسازی نکرده‌ایم.

## نکته مهم قبل از جایگزینی
این بسته مبتنی بر نسخه‌ای است که قبلاً در گفت‌وگو تحت عنوان «Launch Restored» تحویل داده شد و اصلاحات هویتی نقشه را در خود دارد. اگر **پس از آن** فایل‌های `data/companies.json` یا `assets/js/app.js` یا دیگر فایل‌های مشترک را در GitHub تغییر داده‌ای، **این ZIP را بدون مقایسه در شاخه اصلی آپلود نکن**؛ چون جایگزینی فایل مشترک تغییرات بعدی را پاک می‌کند. اول شاخه پشتیبان/آزمایشی بساز و Diff بگیر.

## مسیرهای دقیق فایل‌ها در GitHub
- `index.html` → **ریشه مخزن**؛ برای تغییر نسخه کش JS و داده شرکت‌ها
- `data/companies.json` → پوشه `data/`؛ فایل اصلی ۲۶۶ شرکت/سازمان، با ۶۸ پرونده پرتاب به‌روزشده
- `data/companies_launch.json` → پوشه `data/`؛ ۶۸ پرونده تخصصی پرتاب
- `data/companies_propulsion.json` → پوشه `data/`؛ فقط برای هماهنگی اطلاعات ۳ شرکتی که هم پرتاب و هم پیشرانش هستند
- `assets/js/app.js` → پوشه `assets/js/`؛ نمایش توضیحات فنی، منابع و برچسب وضعیت در سه زبان
- `tests/*.test.cjs` → پوشه `tests/`؛ آزمون سازگاری داده و سه زبان
- `docs/` → پوشه `docs/`؛ گزارش و شناسنامه فیلدها و منابع

## مراحل نصب ایمن
1. در GitHub از وضعیت فعلی `main` یک شاخه پشتیبان ایجاد کن.
2. یک شاخه آزمایشی `launch-deep-restore` بساز.
3. ZIP را **استخراج** کن؛ خود فایل ZIP را به‌جای پوشه‌ها آپلود نکن.
4. فایل‌ها را دقیقاً در **مسیر هم‌نام** قرار بده. لازم نیست فایل‌های دیگر پروژه پاک یا جایگزین شوند.
5. قبل از Merge، Diff فایل `companies.json` و `app.js` را بررسی کن، به‌ویژه تغییرات خودت پس از نسخه مبنا.
6. آزمون‌ها را با دستور `node --test tests/*.test.cjs` اجرا کن.
7. در نسخه آزمایشی سایت، پنجره شرکت‌های SpaceX، Arianespace، Rocket Lab، Stoke، Skyrora، ABL و چند شرکت غیراروپایی را در فارسی/انگلیسی/عربی باز کن و آمار، ناوگان و تاریخچه را بررسی کن.
8. فقط در صورت قبولی بررسی، شاخه آزمایشی را به `main` ادغام کن. برای بازگردانی، از شاخه پشتیبان قبلی استفاده کن.

## مرز علمی
برای بسیاری از شرکت‌ها هنوز رقم معتبر تعداد پرتاب‌ها یا نام دقیق بنیان‌گذار و مدیرعامل در دست نیست. این موارد **با عدد یا شخص ساختگی پر نشده‌اند**. جدول `docs/ISSUES_TO_VERIFY.csv` وضعیت پرونده‌به‌پرونده را نشان می‌دهد.

# راهنمای نصب اصلاحات اولویت اول رسپهر

این بسته **سورس کامل برنامه نیست**؛ فقط تفاوت فایل‌های اولویت اول بازطراحی سه‌بعدی نسبت به سورس نهایی گام هشتم ۲۳ نوامبر ۲۰۲۶ است.

۱. ابتدا نسخه فعلی مخزن GitHub را با مبنا در `MANIFEST.json` تطبیق دهید. اگر فایل‌های اصلی پس از آن ویرایش شده‌اند، فایل‌ها را مستقیم جایگزین نکنید.
۲. از نسخه فعلی مخزن نسخه پشتیبان بگیرید.
۳. ZIP را استخراج کنید و **محتویات** `UPLOAD_TO_GITHUB` را در ریشه مخزن (کنار `index.html`) جایگزین/اضافه کنید.
۴. این پوشه باید در مخزن بماند: `raspehr-3d/`؛ پوشه `UPLOAD_TO_GITHUB` نباید خودش به مخزن کپی شود.
۵. در نسخه آزمایشی Render، نتیجه را روی گوشی بررسی کنید: چرخش، لبه کره، تعداد خوشه‌ها، پنهان‌شدن سمت پشتی، فیلتر ۱۴ دسته و بازشدن کارت خوشه.
۶. برای انتقال به چت بعدی، فایل `raspehr-3d/PRIORITY1_HANDOFF_FA.md` و `raspehr-3d/PRIORITY1_STATE.json` را بدهید.

این بسته فقط اولویت اول است؛ بزرگ‌نمایی تا ساختمان و Bottom Sheet موبایل هنوز انجام نشده‌اند.

**هرگونه انتشار روی GitHub/Render فقط بعد از تصمیم خود کاربر.**

# نصب تغییرات تصاویر محلی رسپهر

**فقط محتویات پوشه `UPLOAD_TO_GITHUB` را در ریشه مخزن GitHub کپی کنید.** ساختار پوشه‌ها حفظ شود. خود پوشه `UPLOAD_TO_GITHUB` را در مخزن قرار ندهید.

**پوشه `ROLLBACK_TO_BASE_ONLY` را بارگذاری نکنید.** این پوشه فقط برای بازگشت به نسخه مبنای این بسته است. قبل از هر نصب یک branch آزمایشی بسازید؛ بهترین برگشت `git revert` است.

**نسخه مبنا:** Stage8 + priorities 1–6 (no separate imagery patch required)

**فایل‌های این بسته:** 11 ویرایش، 66 افزودن، صفر حذف.

**خروجی واقعی:** ۴۸ عکس محلی، از میان ۷۹ پایگاه؛ فقط ۱۱ عکس هوایی و ۱ تصویر راداری. ۲۶ تصویر از تأسیسات و ۱۰ تصویر از عملیات/پرتاب هستند. ۳۱ مورد عکس مناسب ندارند. عکس‌ها از سورس قبلی رسپهر گزینش شده‌اند و منبع و مجوزشان از داده موجود استخراج شده است؛ هیچ عکس ماهواره‌ای جدید دانلود نشده و مجوز مستقل تمام آن‌ها بازتأیید نشده است.

**عملکرد:** روی نشانگر پایگاه در نمای سه‌بعدی کلیک کنید؛ عکس محلی در کارت مکان نمایش داده می‌شود. برای زوم و جابه‌جایی عکس را باز کنید. این یک عکس ثابت است و تغییر زاویه واقعی ۳۶۰ درجه انجام نمی‌دهد.

**پیش‌نمایش پوشش:** `/raspehr-3d/tools/site-views-audit.html`.

**تذکر:** این بسته وابستگی خارجی عکس‌های محلی را برمی‌دارد؛ سرویس‌های مستقل DEM، OSM، OAM و USGS که در امکانات قبلی برنامه هستند ممکن است همچنان به اینترنت وابسته باشند.

قبل از انتشار عمومی، به‌ویژه منبع و مجوز تصویرها را بازبینی کنید و نسخه staging را روی گوشی واقعی بیازمایید. هیچ کدی روی مخزن واقعی منتشر نشده است.

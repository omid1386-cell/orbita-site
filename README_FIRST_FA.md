# رسپهر — بسته فقط تغییرات تجمیعی اولویت‌های ۱ تا ۶ نسبت به گام هشتم

این ZIP **کل اپلیکیشن نیست**. فقط فایل‌های افزوده و ویرایش‌شده نهایی در شش اولویت را نگه می‌دارد. فقط روی سورس **دقیق گام هشتم** استفاده شود.

روش A: نصب ترتیبی بسته‌های P1→P2→P3→P4→P5→P6.
روش B: نصب یک‌باره محتوای UPLOAD_TO_GITHUB از این بسته، روی همان گام هشتم.
**هرگز این دو روش را با هم انجام ندهید.**

نسخه گام هشتم روی GitHub باید با SHA پایه ذکرشده در MANIFEST.json هم‌خوان باشد. اگر مخزن در این فاصله عوض شده، قبل از جایگزینی فایل‌ها ادغام سه‌طرفه لازم است.

ROLLBACK_STAGE8_ONLY فقط برای بازگشت به سورس گام هشتم است؛ روی GitHub بهتر است به Commit قبلی برگردید.

این بسته هنوز روی GitHub/Render منتشر نشده و تأیید عملکرد گوشی و پوشش زنده تصاویر انجام نشده است.

# راهنمای نصب اصلاحات منبع‌محور پرتابگرهای ORBITA

این بسته مخصوص نسخه‌ای است که بسته «ORBITA_Launch_Deep_Recovery_GitHub_READY_2026-11-11.zip» قبلاً روی آن نصب شده است.

## بارگذاری GitHub
1. ابتدا از شاخه فعلی یک بکاپ یا شاخه تازه بساز.
2. این ZIP را استخراج کن؛ پوشه‌های `data/` و `docs/` دقیقاً هم‌نام پوشه‌های گیت‌هاب هستند.
3. در پوشه `data/` سه فایل `companies.json`, `companies_launch.json`, `companies_propulsion.json` را **پس از تطبیق با نسخه فعلی** جایگزین کن.
4. در پوشه `docs/` گزارش و جدول منابع را آپلود کن (اختیاری برای سایت، مفید برای ممیزی).
5. سایت را باز کن و اطلاعات چند شرکت مانند اسپیس‌ایکس، راکت‌لب، فایرفلای، آر‌اف‌ای، کاس‌اسپیس، شهاب/قاصد و اسپیس وان بررسی کن.
6. فایل‌های `assets/js/app.js`, CSS, index.html یا سایر داده‌ها در این نوبت تغییر نکرده‌اند.

هشدار: اگر در GitHub بعد از بسته بازسازی عمیق فایل‌های `companies*.json` ویرایش شده‌اند، جایگزینی مستقیم می‌تواند اصلاحاتت را پاک کند. مشخصات این بسته را طبق `docs/FIELD_CHANGES.csv` ادغام کن.

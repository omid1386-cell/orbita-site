# ORBITA — بستهٔ تغییرات لوگوهای پیشرانش، گام ۱

این ZIP فقط فایل‌های اضافه/تغییریافتهٔ گام ۱ را با مسیرهای اصلی پروژه نگه می‌دارد؛ کل پروژه نیست. گام‌های ۲ و ۳ در این بسته وجود ندارند.

## اعمال روی مخزن

1. ابتدا از مخزن فعلی خود نسخهٔ پشتیبان بگیرید.
2. ZIP را در پوشهٔ ریشهٔ مخزن ORBITA استخراج کنید و در صورت درخواست، فایل‌های موجود را جایگزین کنید.
3. تغییرات را بررسی و سپس commit/push کنید. اگر از GitHub وب استفاده می‌کنید، ZIP را به‌عنوان یک فایل منفرد در مخزن نگذارید؛ محتویات آن را با همان ساختار پوشه‌ها بارگذاری کنید.
4. برای بازآزمایی: `node --check assets/js/app.js` و `node --test tests/*.test.cjs`.

## محتویات

- ۲۲ فایل تصویری لوگو/نشان در `assets/img/logos/`
- دادهٔ اصلی و برش‌های launch/propulsion
- renderer، نسخهٔ cache مربوط به داده و JavaScript، آزمون‌های به‌روزشده/افزوده‌شده
- گزارش فارسی منابع و نتیجه در `reports/propulsion-logo-step1.md`

نکته: دو رکورد `aio-propulsion` و `cubestar` بدون لوگوی تأییدشده باقی مانده‌اند؛ هیچ لوگویی برای آن‌ها در ZIP نیست.

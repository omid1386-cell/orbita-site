# بستهٔ Help و بهبود خوانایی ORBITA

این بسته فایل‌های فعلی رابط ORBITA را در بر دارد و کل پروژه یا سایت مستقل نیست. آن را فقط روی ریشهٔ نسخهٔ هم‌نسخهٔ مخزن ORBITA استخراج کنید و فایل‌های هم‌مسیر را جایگزین کنید.

## محتوای اجرایی

- `index.html`
- `assets/js/app.js`
- `assets/css/app.css`

Help تعاملی شامل جست‌وجو و ۱۷ موضوع حفظ شده است. همچنین متن توضیحی کارت «برنامهٔ محوری» سازمان‌های فضایی و «تاریخچهٔ ساخت محصولات» شرکت‌های پیشران در هر سه زبان خواناتر شده است؛ اندازهٔ قلم **۱۰٫۵ پیکسل** و رنگ‌های تأکیدی تیترها حفظ شده‌اند.

## آزمون‌ها و مستندات

فایل‌های آزمون Help و بررسی توکن cache به همراه assertionهای مرتبط برای نسخهٔ اسکریپت، آزمون‌های شرکت‌های پیشران و مستندات سه‌زبانه داخل بسته‌اند. از ریشهٔ مخزن اجرا کنید:

```sh
node --check assets/js/app.js
node --test tests/site_guide.test.cjs tests/cluster_label_startup.test.cjs
```

آزمون‌های کامل مخزن نیز در محیط ساخت با **۶۸ آزمون موفق و بدون شکست** پایان یافتند:

```sh
node --test tests/*.test.cjs
```

این ZIP داده‌ها، وابستگی‌ها، سایر فایل‌های برنامه یا سرور را شامل نمی‌شود؛ برای اجرا و انتشار به مخزن کامل ORBITA نیاز است.

# بستهٔ تغییرات Help بازطراحی‌شدهٔ ORBITA

این بسته بخش Help تعاملی را برای **نسخهٔ جاری پروژهٔ ORBITA** آماده می‌کند. این فایل ZIP کل پروژه نیست و به‌تنهایی اجرا نمی‌شود؛ به‌عنوان بستهٔ کد، محتویات آن را در ریشهٔ مخزن هم‌نسخهٔ ORBITA استخراج و فایل‌های هم‌مسیر را جایگزین کنید.

## فایل‌های اجرایی اصلی

- `index.html` — ساختار پنل Help و نسخهٔ تازهٔ cache.
- `assets/js/app.js` — متن‌های فارسی/انگلیسی/عربی، جست‌وجو، پیشنهادهای بی‌نتیجه، آیکون‌ها، پیش‌نمایش‌ها و کنش‌های هدایت.
- `assets/css/app.css` — چیدمان واکنش‌گرا و سبک‌های پنل.

## آزمون و مستندات

- آزمون اختصاصی Help و آزمون کنترل توکن‌های cache در `tests/`.
- نقشه و پیش‌نویس محتوای فارسی/انگلیسی/عربی در فایل‌های Markdown ریشه.

از ریشهٔ مخزن، برای آزمون‌های بسته اجرا کنید:

```sh
node --check assets/js/app.js
node --test tests/site_guide.test.cjs tests/cluster_label_startup.test.cjs
```

این دو آزمون **۱۱ مورد** را پوشش می‌دهند. در محیط ساخت، اجرای کامل پروژه نیز با **۶۸ آزمون موفق و بدون شکست** تأیید شده است؛ برای اجرای آن همهٔ فایل‌های پروژه لازم‌اند:

```sh
node --test tests/*.test.cjs
```

این بسته داده‌ها، سایر بخش‌های سایت، وابستگی‌ها یا سرور را در بر نمی‌گیرد. برای راه‌اندازی و انتشار، از مخزن کامل ORBITA استفاده کنید.

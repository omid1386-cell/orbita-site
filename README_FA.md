# رَسپهر — کوتاه‌کردن فاصله صفحه آغازین تا نقشه

## تغییر اصلی
صفحه آغازین قبلاً تا رویداد کامل `load` در MapLibre باقی می‌ماند. این رویداد ممکن است منتظر دریافت کاشی‌های دوردست و منابع ثانویه بماند.
در این نسخه، صفحه آغازین پس از آماده‌شدن استایل اولیه و رسم نخستین فریم نقشه کنار می‌رود؛ دریافت کاشی‌ها و داده‌های تکمیلی در پس‌زمینه ادامه دارد.

## رفتار زمانی
- حداقل نمایش برند: ۷۵۰ میلی‌ثانیه؛ برای اینکه لوگوی کامل اسپاش و نام رَسپهر فرصت ظهور نرم داشته باشند.
- سقف نمایش صفحه آغازین: ۲۳۰۰ میلی‌ثانیه؛ حتی اگر نقشه دیرتر آماده شود، کاربر پشت لوگو منتظر نمی‌ماند.
- مدت محوشدن صفحه آغازین: ۲۸۰ میلی‌ثانیه.
- انیمیشن ورود لوگو و نوشته‌ها کوتاه‌تر شده، اما ترتیب و پالت رنگی حفظ شده است.

## اصلاح پیام بارگذاری
پیام وضعیت نقشه دیگر با یک تایمر ثابت ۲ ثانیه‌ای مخفی نمی‌شود؛ تا رسم نخستین فریم نقشه باقی می‌ماند. بنابراین اگر نقشه دیرتر برسد، کاربر به‌جای صفحه خالی، پیام بارگذاری را می‌بیند.

## حفظ کش و داده‌ها
فقط URL فایل‌های JavaScript تغییرکرده نسخه‌گذاری شده‌اند. شناسه نسخه داده‌ها و فایل‌های داده‌ای دست‌نخورده‌اند تا مرورگر مجبور نشود بانک‌های بزرگ و بدون تغییر را دوباره دریافت کند.

## فایل‌های بسته افزایشی
- `index.html`
- `assets/js/app.js`
- `assets/js/raspehr-splash.js`

## نصب
این بسته برای نسخه‌ای است که قبلاً اصلاح سرعت و صفحه آغازین رَسپهر روی آن نصب شده باشد.
فایل‌ها را استخراج و با حفظ مسیر پوشه‌ها در ریشه مخزن GitHub جایگزین کنید؛ خود ZIP را به‌عنوان یک فایل در مخزن بارگذاری نکنید.
پس از انتشار، سایت را با Hard Refresh باز کنید.

## محدودیت آزمون
آزمون نحوی JavaScript، کنترل نسخه‌گذاری کش، وجود رویداد نخستین فریم و سلامت ZIP انجام شده است. زمان نهایی روی سایت زنده به پاسخ Render و میزبان نقشه وابسته است و باید پس از انتشار در مرورگر واقعی سنجیده شود.

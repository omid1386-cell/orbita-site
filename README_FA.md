# ORBITA — بستهٔ افزایشی لوگوهای پیشرانش، گام ۲

این بسته فقط فایل‌های افزوده یا تغییر‌یافتهٔ گام ۲ را دارد؛ کل پروژه نیست.

## پیش‌نیاز و روش اعمال

1. اگر مخزن GitHub هنوز تغییرات گام ۱ را نگرفته، ابتدا فایل `orbita-propulsion-logo-step1-github.zip` را روی ریشهٔ مخزن اعمال کنید. پشتیبانی نمایش لوگو در `assets/js/app.js` در همان گام ۱ اضافه شده است و در این بسته تکرار نمی‌شود.
2. این بسته را نیز در ریشهٔ مخزن استخراج کنید و فایل‌های هم‌نام را جایگزین کنید.
3. فایل‌ها را با همان مسیرها در مخزن بررسی و بارگذاری کنید. خود فایل ZIP را به‌تنهایی داخل مخزن نگذارید؛ محتویات آن را در جای درست قرار دهید.
4. برای آزمون پس از اعمال: `node --check assets/js/app.js` و `node --test tests/*.test.cjs`.

## محتویات این گام

- ۱۹ فایل نشانِ یکتا برای ۲۲ رکورد؛ سه نشانِ Roscosmos و دو نشانِ NASA میان رکوردهای مربوطه مشترک‌اند.
- دادهٔ اصلی و برش پیشرانش، نسخهٔ cache جدید، آزمون اختصاصی گام ۲، آزمون‌های نسخه‌به‌روزشده و گزارش فارسی.
- برای `ion-satellite` و `nakuja-project` لوگوی تأییدنشده اضافه نشده است.

این بسته شامل کد کامل پروژه، فایل‌های گام ۱، آرشیو پوشهٔ کاری یا فایل‌های پروژهٔ اروپا نیست.

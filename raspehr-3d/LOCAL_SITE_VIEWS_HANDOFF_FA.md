# رسپهر — سند انتقال نمای تصویری محلی پایگاه‌های پرتاب
تاریخ ۲۵ نوامبر ۲۰۲۶

## آنچه پیاده‌سازی شده
نمایشگر عکس واقعی، محلی، کشیدنی، زوم و دو‌انگشتی در کره سه‌بعدی؛ ۴۸ پایگاه با یک عکس موجود و منبع/مجوز اعلام‌شده، ۳۱ پایگاه بدون عکس مناسب. هیچ تصویر ماهواره‌ای تازه از وب دانلود نشده است. این قابلیت تصویر تخت است، نه ۳۶۰ درجه و گوگل‌ارث واقعی.

## وابستگی بسته
نسخه نهایی از سورس گام هشتم + شش اولویت سه‌بعدی + اصلاحات قبلی IMAGERY_NEAR_VIEW_INSTALL_PATCH ساخته شده است. بسته تجمیعی این تحویل برای GitHub دارای **پایه دقیق Stage8 + اولویت‌های ۱ تا ۶** است. اگر پچ تصویر قبلی نصب شده باشد نیز می‌توان از نسخه نهایی فایل‌ها استفاده کرد اما وضعیت rollback متفاوت است؛ اولویت با یک branch و استفاده از Git Revert است.

## ساختار داده
`raspehr-3d/data/site-views-local.v1.json` فهرست ۷۹ ردیفی، شناسه، برچسب نوع، مسیر فایل JPG، ابعاد، SHA-256، نام صاحب اثر، مجوزِ اعلام‌شده و لینک منبع را دارد. ۴۸ عکس در `raspehr-3d/assets/site-views/photos/` نگهداری می‌شوند. داده‌های اصلی ۴۲۰ شناسنامه و مختصات تغییر نکرده است.

## فایل‌های اجرایی
`raspehr-3d/assets/js/site-views.js` ، `raspehr-3d/assets/css/site-views.css` ، `raspehr-3d/index.html` ، `raspehr-3d/assets/js/prototype.js` ، `assets/js/raspehr-stage5-switch.js` ، `index.html`.

## وضعیت آزمون
۲۶ فایل Node test موفق؛ Chromium ۳۹۰/۱۲۸۰ موفق؛ WebGL واقعی SwiftShader با fixture داده خارجی، ۴۲۰ پرونده، انتخاب نشانگر، زوم و نمایشگر موفق. اتصال وب عمومی/گوشی حقیقی آزمون نشده.

## موارد باز
۳۱ پایگاه تصویر ندارد؛ در ۱۰ مورد عکس فقط عملیات است، نه نمای کلی؛ ۲۶ مورد نمای قسمتی از تأسیسات؛ فقط ۱۲ نما هوایی/راداری‌اند. مجوز بازنشر بر اساس داده پیشین است و بازتأیید حقوقی مستقل انجام نشده. برای عکس‌های جدید به اتصال اینترنت یا دریافت فایل از مالک منبع نیاز است. موقعیت دقیق و نمای ۳۶۰ درجه هنوز پروژه‌ای جداگانه‌اند.

## ادامه در چت تازه
بسته ZIP و این سند را بدهید. هر تغییر آینده باید delta GitHub با SHA256، rollback و گزارش QA باشد؛ بدون دستور کاربر روی GitHub/Render منتشر نشود.

# گزارش QA و آمادگی انتشار — رسپهر، اولویت ششم

**تاریخ:** ۲۵ نوامبر ۲۰۲۶  
**تصمیم انتشار فعلی:** NOT APPROVED / NO-GO برای انتشار عمومی، تا آزمون سایت و دستگاه واقعی.

## مرور نتایج

| موضوع | نتیجه | مرز اعتبار |
|---|---|---|
| تست‌های 3D Node/CJS | ۲۱/۲۱ PASS | منطق کد، داده، دوربین، نشانگر، موبایل، منابع |
| smoke قدیمی | PASS | مسیر ابزار مرحله اول |

| مرورگر responsive | PASS در ۳۲۰، ۳۹۰، ۶۶۷ افقی، ۱۲۸۰ | شبیه‌سازی موبایل در Chromium |

| شناسنامه‌ها و گالری | PASS | نمونه‌های شرکت، پایگاه، بازیابی و کشور |

| گوشی فیزیکی / Render | NOT TESTED | هنوز نسخه جدید منتشر نشده |

## اصلاح مستقل این مرحله
- نسخه‌گذاری URL منابع اجرایی سه‌بعدی و آدرس iframe برای کاهش ریسک کش قدیمی مرورگر.
- عنوان واقعی و غیرآزمایشی صفحه سه‌بعدی.
- ابزارهای release-audit، staging-smoke و بررسی زنجیره ZIPها.

## آزمون ممیزی HTTP
اسکریپت `staging-smoke.py` روی سرور محلی با ۱۴ کنترل عبور کرد. در اولین نسخه این ابزار، بارگیری JSON بزرگ شرکت‌ها محدود و ناقص بود؛ سقف به ۲۰ مگابایت افزایش یافت و پاسخ کامل JSON بازآزمایی شد (۱۴/۱۴). این اصلاح ابزار بود، نه تغییر داده اصلی.

## ملاحظات آزمون‌های میراثی
نتایج ۶۵ فایل آزمون قدیمی پیش از این تغییر و پس از آن یکسان‌اند: ۳۰ پاس و ۳۵ شکست. این ۳۵ فایل شامل آزمون‌های تاریخ‌گذشته و آزمون‌های وابسته به API داخلی قدیمی نیز هستند؛ **هیچ‌کدام را بدون بررسی جداگانه منسوخ یا بی‌خطر فرض نمی‌کنیم**. نیاز به triage پیش از تأیید عمومی باقی است.

## نتیجه
نسخه نهایی از نظر ساختار و آزمون‌های قابل اجرای محیط داخلی آماده تحویل به **شاخه staging** است، اما وضعیت انتشار عمومی تا آزمون عملی و تعیین تکلیف مشکلات مهم **NO-GO** باقی می‌ماند.

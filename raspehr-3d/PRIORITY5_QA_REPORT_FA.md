# گزارش کنترل کیفیت اولویت پنجم رسپهر

**تاریخ:** ۲۵ نوامبر ۲۰۲۶  
**مبنا:** نسخه کاری اولویت چهارم (گام هشتم + اولویت‌های ۱ تا ۴)  
**محدوده:** جلوه‌های بصری کره/خوشه/برچسب انتخابی/پنل‌ها.

## نتایج اصلی

| معیار | نتیجه |
|---|---|
| مجموعه آزمون‌های Node/CJS | ۲۰ از ۲۰ موفق |
| انتخاب/هاله/برچسب متصل به کره | موفق؛ شامل مخفی‌سازی نیمکره پشتی |
| حلقه انتخاب در زوم نزدیک و دور | موفق؛ شعاع پیکسلی کنترل‌شده |
| نشانگر تقریبی | برچسب «نقطه مرجع» حفظ شد |
| خوشه‌بندی و لمس | موفق؛ قطر ۲۷–۳۴ پیکسل و محدوده لمس حدود ۴۵ پیکسل |
| نمایش موبایل ۳۲۰، ۳۹۰ و افقی ۶۶۷ | موفق، بدون سرریز افقی |
| نمایش دسکتاپ ۱۲۸۰ | موفق |
| آزمون ۲۴۰ وضعیت دوربین | موفق |
| WebGL واقعی Chromium/SwiftShader | موفق، خطای JS صفر |
| شناسنامه، گالری، نمای نزدیک تأسیسات | مسیر تعامل موفق با fixtureهای محلی |
| سلامت ZIP و آزمون ادغام/بازگشت | در بسته نهایی با SHA-256 تأیید شده |

## جزییات و مرز شواهد

- **تست WebGL واقعی** به خود موتور Three.js و رندر Chromium/SwiftShader متصل بود؛ شامل ۴۲۰ شناسنامه، ۱۴ دسته، نشانگر انتخابی و گذار موبایل/دسکتاپ شد.
- تصاویر محلی و ساختمان‌های آزمون همچنان با داده مصنوعی و ثابت آزمایش شدند. تصاویر ماهواره‌ای با وضوح واقعی برای تک‌تک پایگاه‌ها در این آزمون تأیید نشده‌اند.
- **تست مرورگر موبایل** شبیه‌ساز Chromium است؛ نه آزمایش روی گوشی فیزیکی کاربر.
- تأیید عملکرد روی Render و استقرار واقعی انجام نشده است.
- API داده، نقشه دوبعدی، منابع media، داده پرتاب و فرود، منطق اصلی خوشه‌بندی و آرشیو JSON تغییری نکرده‌اند.

## ریسک‌های پابرجا

1. تست روی گوشی واقعی (مرورگر Android/iOS، GPU/لمس/پایداری) باقی است.
2. سرورهای خارجی تصاویر/footprint ممکن است به داده واقعی یا مجوز مناسب دسترسی ندهند.
3. برخی از ۴۲۰ مختصات نماینده و تقریبی‌اند؛ انتخاب بصری به معنای مکان قطعی ساختمان نیست.
4. ۴۹ شکست قدیمی آزمون عمومی و ۳۸ لوگوی ثبت‌شده اما فاقد فایل در محدوده این کار قرار ندارند.

## نصب

این ZIP فقط دلتا نسبت به اولویت چهارم است؛ ابتدا بسته‌های ۱ تا ۴ را به ترتیب روی نسخه گام هشتم اعمال کنید. داخل ZIP پوشه‌های `UPLOAD_TO_GITHUB/` (تغییرات) و `ROLLBACK_PRIORITY4_ONLY/` (بازگشت) و `MANIFEST.json` موجودند. **هیچ انتشار انجام نشده است.**

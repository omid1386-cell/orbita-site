# راهنمای گام سوم رسپهر — جست‌وجو، فیلتر و خوشه‌بندی کره سه‌بعدی

این بسته، **نسخه تکمیل‌شده از نظر پیاده‌سازی و آزمون خودکار گام سوم** است؛ جایگزین گام‌های دوم یا فایل‌های نقشه دوبعدی نمی‌شود.

## قابلیت‌ها
- جست‌وجوی نام فارسی/انگلیسی، شهر، کشور و شناسه؛ پشتیبانی از معادل‌سازی حروف فارسی/عربی و ارقام فارسی/عربی
- انتخاب یک کشور/قلمرو دقیقاً بر پایه فیلد کشور ثبت‌شده در داده، بدون ایجاد کشور یا مختصات مصنوعی
- ۱۴ فیلتر دسته با عملگر «یا» در مورد رکوردهای دارای چند عضویت؛ هر موجودیت یکتا حداکثر یک نشانگر
- خوشه‌بندی براساس فاصله صفحه‌ای نقاط قابل‌مشاهده و تغییر با دوربین و زوم
- نشان دادن شمار اعضای خوشه و لیست کوتاه اعضا، بزرگ‌نمایی به مرکز جغرافیایی آن
- شمار نتیجه‌های منطبق با فیلتر، تعداد نقاط در سمت قابل مشاهده و تعداد خوشه‌ها
- استفاده مستقیم از فایل‌های اصلی `data/companies.json`، `data/sites.json`، `data/recovery_sites.json`

## اجرا
در ریشه کامل مخزن، فایل `raspehr-3d/index.html` را از طریق یک وب‌سرور استاتیک باز کنید. بازکردن مستقیم با `file://` ممکن است مانع Fetch داده‌ها شود.

**محدوده:** فقط ماژول `raspehr-3d/` تغییر کرده است. سورس نقشه دوبعدی و JSONهای مرجع دست‌نخورده‌اند. اتصال به پنل شناسنامه کامل در گام چهارم انجام می‌شود.

## آزمون‌ها
در ریشه مخزن:

```bash
node raspehr-3d/tests/stage3_explore.test.cjs
node raspehr-3d/tests/stage3_markers.test.cjs
```

آزمون مرورگر اختیاری (نیازمند Chromium، Playwright و Xvfb):

```bash
xvfb-run -a python raspehr-3d/tests/stage3_browser.py
```

این آزمون، کره WebGL و رابط جست‌وجو و فیلتر را روی داده‌های واقعی می‌سنجد، اما برای آفلاین ماندن آزمون، فقط انتقال تصویر و سرویس DEM را شبیه‌سازی می‌کند.

## محدودیت‌ها
- ۲۳ مورد فاقد مختصات **عمداً** بدون تغییر باقی مانده‌اند و برای پایان تمام گام‌ها ثبت شده‌اند.
- تصاویر سه‌بعدی از تصاویر چندسطحی گام اول استفاده می‌کنند؛ DEM واقعی محلی هنوز فراهم نشده است.
- کلیک و بزرگ‌نمایی خوشه‌ها، حفظ دکمه زیر لمس، رگرسیون فیلترها، نمایش پاسخ‌گو و آزمون فشار ۲۴۰ تغییر متوالی دوربین در Chromium دسکتاپ و حالت شبیه‌سازی موبایل اجرا و موفق شد. این آزمون از یک موتور صحنه کنترل‌شده با Three.js و داده واقعی استفاده کرد؛ آزمون مجدد مستقیم WebGL در این نوبت به محدودیت زمان محیط رسید.
- عملکرد روی گوشی فیزیکی، شبکه کند، WebGL تولیدی و سایت Render تأیید نشده است و بخشی از دروازه آزمون نهایی قبل از انتشار باقی می‌ماند.
- برخی کشور/قلمروهای مرکب مستقیماً از برچسب‌های منبع آمده‌اند؛ این نسخه آن‌ها را تجزیه یا به کشور مستقل تبدیل نمی‌کند.
- این بسته **هیچ تعاملی با شناسنامه کامل یا پنل ۲بعدی ندارد**؛ این‌ها گام ۴ و ۵ هستند.

## آزمون تکمیلی گام سوم

```bash
python raspehr-3d/tests/stage3_qa_browser.py
```

این آزمون Playwright/Chromium (دسکتاپ ۱۳۶۶×۹۰۰ و شبیه‌سازی موبایل ۳۹۰×۸۴۴)، داده‌ها و فایل‌های واقعی واسط را به‌کار می‌گیرد، ولی موتور رندر صحنه را برای اجرای قطعی و سریع با موتور کنترل‌شده Three.js جایگزین می‌کند. از آن برای اثبات کارکرد روی GPU یا گوشی واقعی استفاده نکنید.

گزارش فنی کامل این دور: `STAGE3_QA_REPORT_FA.md`.

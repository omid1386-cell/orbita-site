# گام ششم رسپهر — راهنمای اجرا

گام ششم به‌صورت افزایشی روی نسخه تجمیعی گام پنجم اعمال شده و نیازمند استقرار وب‌سرور است؛ بازکردن `file://` برای بارگذاری JSON و بافت‌ها کافی نیست.

- صفحه اصلی: `index.html`
- ماژول کره: `raspehr-3d/index.html`
- تنظیم‌های عملکرد: «هوشمند»، «کم‌مصرف»، «متعادل» و «جزئیات بیشتر»؛ انتخاب حالت، کیفیت اولیه تصویر و سقف رندر را هماهنگ می‌کند.
- در نمای دوبعدی، iframe سه‌بعدی حفظ ولی رندر آن متوقف می‌شود؛ با انتخاب دوباره سه‌بعدی، رندر بدون بازنشانی نمای کاربر شروع می‌شود.
- تست‌های محلی: `node raspehr-3d/tests/stage6_performance.test.cjs` و `node raspehr-3d/tests/stage6_lifecycle.test.cjs`
- اجرای همه تست‌های Node: از پوشه `raspehr-3d` برای هر فایل `tests/*.test.cjs` و نیز `tests/stage1_smoke.cjs`.

**احتیاط:** هسته WebGL روی وب‌سرور و گوشی واقعی هنوز آزمون end-to-end نشده است. قبل از انتشار عمومی باید دستگاه کم‌توان، حالت تغییر سریع نقشه، تعامل با گالری و بازیابی بعد از قطع WebGL آزمون شود.

۲۳ شناسنامه فاقد مختصات از گام دوم برای بررسی در پایان پروژه باز می‌مانند.

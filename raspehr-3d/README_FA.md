# رسپهر — بسته تجمیعی نهایی توسعه گام اول نقشه سه‌بعدی

**ویرایش R7 — تاریخ ۲۲ نوامبر ۲۰۲۶**

## محدوده
این بسته فقط ماژول مستقل `raspehr-3d/` است و برای **گام اول** تهیه شده: زمین کروی سه‌بعدی، ناوبری، تصویر روز و شب، تصاویر چندسطحی و نمونه DEM هندسی. هیچ شرکتی، پایگاه پرتاب، شناسنامه، نشانگر یا داده ماهواره‌ای به برنامه اضافه نشده است؛ آن‌ها به مراحل بعد مربوط‌اند.

## اجرای نمونه
1. پوشه `raspehr-3d/` را در **ریشه همان مخزن اصلی رسپهر** قرار دهید. این بسته با فایل‌های اصلی نقشه دوبعدی تداخل ندارد.
2. دو وابستگی لازم از قبل در مخزن اصلی وجود دارند و عمداً در این بسته تکرار نشده‌اند:
   - `assets/vendor/three.min.js`
   - `assets/tex/earth_day.jpg`, `earth_night.jpg`, `earth_clouds.jpg`, `earth_normal.jpg`, `earth_spec.jpg`
3. از ریشه پروژه با وب‌سرور استاتیک اجرا کنید (برای مثال `python -m http.server 8000`) و آدرس `http://localhost:8000/raspehr-3d/` را باز کنید. بازکردن مستقیم فایل با `file://` برای دریافت بافت‌ها/DEM قابل اتکا نیست.
4. نسخه فعلی ورودی اصلی سایت یا مسیر نقشه دوبعدی را عوض نمی‌کند. **انتشار روی GitHub/Render انجام نشده است**؛ فقط فایل آماده تحویل است.

## قابلیت‌های گام اول
- کره زمین Three.js با حرکت ماوس/لمس، زوم، اینرسی کنترل‌شده، هشت نمای سریع و تنظیمات گرافیکی.
- جلوه روز/شب بر اساس موقعیت ظاهری خورشید، جو، ستارگان، ابرهای ثابت و بازتاب/سایه‌روشن تصویری.
- **سه سطح تصویر مجزا**: `z0` برابر تصویر سراسری ۲۰۴۸×۱۰۲۴، `z1` برابر ۴۰۹۶×۲۰۴۸، `z2` برابر ۸۱۹۲×۴۰۹۶. هر سطح از قطعه‌های ۱۰۲۴×۱۰۲۴ تشکیل شده و مجموع بافت‌های روز/شب ۸۴ فایل است.
- انتخاب سطح با فاصله دوربین همراه با hysteresis؛ جلوگیری از جایگزینی تصویر توسط درخواست‌های قدیمی و آزادسازی درست بافت‌های جایگزین.
- تغییر کیفیت ۲K/۴K/۸K، با محدودسازی حالت ۸K روی دستگاه‌های کم‌حافظه.
- ماژول هندسی DEM مبتنی بر Mapzen/AWS Terrarium با خواندن ۱۶ tile در سطح ۲، نمونه‌برداری bilinear، و تغییر واقعی هندسه کره؛ امکان خاموش‌کردن و مقیاس‌های ۱×، ۲× و ۴×. پیش‌فرض هندسی **۱× واقعی** است.
- پیام پیشرفت و خطای DEM، دکمه تلاش مجدد و بازگشت به زمین بدون جابه‌جایی هندسی هنگام شکست شبکه.

### توجه به وضوح تصویر
سه سطح تصویری جدید **از منبع اصلی ۸K موجود در رسپهر استخراج شده‌اند**. تغییر سطح، تعداد پیکسل نمای دور/میانی/نزدیک را واقعاً تغییر می‌دهد، اما **تصاویر تازه با وضوح محلی بالاتر از منبع ۸K به دست نمی‌آورد**. بنابراین زوم تا سطح شهر/ساختمان مشابه Google Earth هنوز ممکن نیست و در محدوده گام اول وعده داده نمی‌شود.

### توجه به DEM
نسخه فعلی به داده Terrarium سطح ۲ نیاز دارد؛ این سطح برای نمای کلی جهان است و دقت محلی/کوهستانی بالایی ندارد. قطب‌ها در Web Mercator بالاتر از حدود ۸۵ درجه داده ندارند و نسخه حاضر ارتفاع منفی را برای حفظ سطح آب صفر می‌کند.

## قطع وابستگی مرورگر کاربر به AWS
پیش‌فرض برنامه درخواست زنده از `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/` دارد؛ **موفقیت درخواست مستقیم مرورگر از AWS/CORS تضمین‌شده نیست**. برای راه‌اندازی مطمئن‌تر و هم‌مبدأ، یک بار روی سیستمی که به AWS دسترسی دارد دستور زیر را اجرا کنید:

```bash
python raspehr-3d/tools/fetch_dem_z2.py
```

ابزار فقط پس از دریافت کامل ۱۶ tile واقعی PNG، بررسی اندازه ۲۵۶×۲۵۶ و تولید manifest، تنظیمات `assets/js/terrain-source.js` را برای استفاده از مسیر محلی `assets/dem/terrarium/` بازنویسی می‌کند. فایل‌های دانلودشده را همراه با پوشه `raspehr-3d/` منتشر کنید.

**در محیط تولید این بسته، ارتباط مستقیم به AWS مقدور نبود و فایل‌های DEM واقعی دانلود/ضمیمه نشده‌اند.** اجرای ابزار بر عهده محیطی است که دسترسی شبکه داشته باشد؛ در صورت عدم دسترسی، زمین تصویری و ناوبری همچنان کار می‌کنند و terrain هشدار می‌دهد.

## آزمون‌ها
از ریشه مخزن:

```bash
node raspehr-3d/tests/stage1_smoke.cjs
node raspehr-3d/tests/stage1_imagery_r7.test.cjs
node raspehr-3d/tests/terrain_dem.test.cjs
node raspehr-3d/tests/terrain_r6.integration.test.cjs
node raspehr-3d/tests/terrain_geometry_real_three.test.cjs
python raspehr-3d/tests/verify_stage1_assets.py
python raspehr-3d/tests/verify_dem_downloader.py
```

Python image checks require Pillow. Geometry tests use همان `assets/vendor/three.min.js` مخزن. آزمون‌ها در این تحویل موفق بودند؛ اما **رندر واقعی WebGL با موتور نرم‌افزاری SwiftShader در Chromium/Xvfb تأیید شد**؛ سه سطح z0/z1/z2 با موفقیت نمایش داده شدند. اما نرخ فریم دستگاه‌های واقعی و دسترسی AWS روی Render/موبایل هنوز تأیید نشده است. گام اول به عنوان **بسته توسعه آماده برای آزمون استقرار** جمع‌بندی شده، نه مجوز ادعای آزمون‌شدن در محیط تولید.

## آزمون اختیاری واقعی WebGL روی لینوکس

```bash
xvfb-run -a python raspehr-3d/tests/browser_webgl_r7.py
```

نیازمند Chromium و Playwright است؛ تصاویر به‌صورت data URL محلی و DEM به‌صورت **داده آزمایشی** فراهم می‌شوند. این آزمون رندر واقعی نرم‌افزاری را بررسی می‌کند، نه بارگیری آنلاین یا نرخ فریم کارت گرافیک اصلی.

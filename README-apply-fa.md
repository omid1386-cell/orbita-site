# بستهٔ به‌روزرسانی محدود اروپا برای ORBITA

این بسته یک **overlay محدود به دامنهٔ اروپا** است؛ نسخهٔ کامل پیش‌نمایش محلی نیست و تغییرهای غیراروپایی را منتقل نمی‌کند.

## مبنای تازه

- سایت عمومی: <https://orbita-site.onrender.com/>
- توکن نسخهٔ مبنا: `20261106contactaudit1`
- مبنای تأییدشده: ۱۸۸ شرکت و ۷۲ سایت
- فایل `BASELINE_SHA256.txt` هش ۸ فایل مبنا را ثبت می‌کند؛ هش `data/companies_satmaker.json` فقط برای اطمینان از دست‌نخوردن آن است.

پیش از بارگذاری، هش‌های نسخهٔ مقصد را با `BASELINE_SHA256.txt` تطبیق دهید. اگر حتی یکی از فایل‌های مبنا فرق داشت، بسته را روی آن نسخه اعمال نکنید؛ ابتدا مقایسه را از نو بسازید.

## فایل‌های اجرایی که باید جایگزین شوند

فقط این ۷ فایل runtime از ریشهٔ مخزن جایگزین شوند:

1. `index.html`
2. `assets/js/app.js`
3. `data/companies.json`
4. `data/companies_launch.json`
5. `data/companies_propulsion.json`
6. `data/companies_agency.json`
7. `data/sites.json`

`data/companies_satmaker.json` و CSS عمداً در بسته نیستند و باید بدون تغییر بمانند. توکن کش در `index.html` به `20261106contactaudit1-europe1` تغییر کرده است.

پوشهٔ `changes/` شامل patchهای JSON برای بازبینی است؛ `docs/SOURCES_AND_LIMITATIONS.fa.md` و `VALIDATION_REPORT.fa.md` اسناد همراه‌اند، نه فایل‌های لازم برای اجرای سایت. `PATCH_MANIFEST.txt` فهرست دقیق محتویات ZIP را می‌دهد.

## دامنه و شمارش

- ۵۷ رکورد شرکتی اضافه؛ ۴ رکورد موجود به‌روزرسانی؛ `yuzhmash` با دو رکورد جداگانهٔ `pivdenmash` و `pivdenne` جایگزین.
- خروجی: ۲۴۴ شرکت و ۷۳ سایت.
- دستهٔ اصلی شرکت‌ها: `launch=69`, `propulsion=66`, `agency=81`, `satmaker=28`.
- عضویت خام در برش‌ها: `launch=69`, `propulsion=69`, `agency=81`, `satmaker=28`.
- شمار canonical که UI نمایش می‌دهد: `launch=69`, `propulsion=68`, `agency=81`, `satmaker=28`. اختلاف برش propulsion به یک alias پیوندی (`casc-6th`) مربوط است که نشانگر مستقل نمی‌گیرد.
- سه عضویت ثانویهٔ پیشرانش فقط برای `borospace`, `hyprspace` و `otespace` افزوده شده؛ نشانگر تکراری ساخته نمی‌شود. در نمای کشور، یک شرکت چندعضوی در «کل مراکز فعال» فقط یک‌بار شمرده می‌شود، هرچند شمار تب‌های دسته‌ای جداگانه است.

ردهٔ `launch` لایهٔ **صنعت پرتاب** است و به‌تنهایی به معنی اپراتور پرتاب مداری نیست؛ در شرح رکوردها، اپراتور، یکپارچه‌ساز، سازنده و توسعه‌دهندهٔ زیرمداری/آزمایشی از هم جدا شده‌اند.

## تصمیم‌های محدودکنندهٔ مهم

- `Delta V` در دستهٔ عمومی نسخهٔ مبنا (`launch`) باقی مانده است؛ بازرده‌بندی آن از نسخهٔ محلی به `propulsion` بدون مجوز وارد بسته نشد.
- رکوردهای موجودِ نامرتبط، از جمله `ihi-aerospace`، عیناً حفظ شده‌اند. چهار به‌روزرسانی فقط `roketsan`, `dlr-germany`, `roscosmos` و `uksa-uk` هستند.
- `Roketsan` سازنده/توسعه‌دهندهٔ سامانهٔ پرتاب در حال توسعه ثبت شده، نه اپراتور مداری. ۱۹۸۸ فقط سال تأسیس است؛ سال نخستین پرواز مداری، ناوگان مداری و آمار پرتاب تأییدنشده خالی/نامعلوم مانده‌اند.
- `Malbusca` به‌عنوان مرکز پرتغالیِ دارای مجوز و تحت بهره‌برداری افزوده شده است. «فعال» دربارهٔ خود مرکز است؛ آزمون‌های GAMA جوی بوده‌اند و مجوز مرکز به‌تنهایی مجوز هیچ پرتاب مشخصی نیست.
- رکوردهای فرانسهٔ گویان، از جمله محل Kourou، با نام قلمرو `French Guiana` حفظ شده‌اند و به فرانسهٔ سرزمین اصلی تغییر نام نداده‌اند. Cornwall نیز به‌واسطهٔ تطبیق زیررشته‌ای به محل دیگری تبدیل نشده است. دامنه بر فهرست بازبینی‌شده و نام‌های دقیق تکیه دارد.
- فهرست بازبینی‌شده دو مورد قفقاز جنوبی، `azercosmos` و `geocosmos`، را صریحاً در دامنهٔ منطقه‌ای گنجانده است؛ هر دو در فایل‌ها با کشور و نقش حقوقی واقعی خود باقی می‌مانند، نه بر پایهٔ تطبیق متن.

## روش بارگذاری دستی

1. ZIP را روی یک clone تازه از همان نسخهٔ عمومی بازبینی کنید و هش‌های مبنا را بسنجید.
2. هفت فایل runtime بالا را در مسیرهای دقیق خود جایگزین کنید.
3. `data/companies_satmaker.json` و فایل‌های CSS را جایگزین نکنید.
4. patchهای `changes/` را برای audit نگه دارید؛ آن‌ها جایگزین فایل‌های کامل runtime نیستند.
5. سپس خودتان تغییرها را در GitHub بارگذاری کنید. این بسته نه commit ساخته، نه push کرده و نه deploy انجام داده است.

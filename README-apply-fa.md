# بستهٔ افزایشی اصلاح pan و marker — ۴ نوامبر ۲۰۲۶

این ZIP فقط **اصلاح اخیر markerهای بازیابی** را بسته‌بندی می‌کند؛ snapshot کامل ORBITA نیست و جایگزین بستهٔ قبلی بهینه‌سازی آغاز نمی‌شود.

## پیش‌نیاز مهم

این بسته برای شاخه‌ای ساخته شده که نسخهٔ قبلی پروژه/بهینه‌سازی آغاز را دارد و در `index.html` توکن `20261103boot-opt1` بوده است. اگر بستهٔ قبلی را هنوز وارد شاخه نکرده‌اید، این ZIP به‌تنهایی همهٔ تغییرات قبلی را ندارد؛ فایل‌های آن را با شاخهٔ GitHub خود مقایسه کنید یا ابتدا بستهٔ قبلی را اعمال کنید.

## محتوای تغییر

- `assets/css/app.css`: حذف transition از transform ریشهٔ `.pin` که MapLibre برای موقعیت جغرافیایی marker به‌روز می‌کند؛ انتقال انیمیشن hover به SVG داخلی با همان scale و مدت ۱۴۰ms.
- `index.html`: افزایش cache token به `20261104panfix1`.
- `tests/`: تست regression جدید و به‌روزرسانی انتظار cache token در تست‌های موجود.
- `.work/`: دو harness اختیاری Playwright برای سنجش drift و drag. این‌ها ابزار QA هستند و برای اجرای سایت لازم نیستند.
- `README-apply-fa.md` و `PATCH_MANIFEST.txt`: راهنمای اعمال و فهرست فایل‌های بسته.

هیچ فایل `assets/js/app.js`، دادهٔ کامل شرکت‌ها، هندسهٔ کامل کشورها یا قابلیت runtime دیگری در این اصلاح تغییر نکرده است؛ این فایل‌ها عمداً در بسته نیستند.

## روش استفاده

1. از شاخهٔ مقصد backup بگیرید.
2. ZIP را در **ریشهٔ پروژهٔ ORBITA** استخراج کنید تا مسیرهای `assets/`, `tests/` و `.work/` حفظ شوند.
3. چون `index.html` و `assets/css/app.css` در بسته نسخهٔ کامل فایل‌اند، اگر روی شاخهٔ شما تغییر مستقل دیگری در آن دو فایل هست، پیش از جایگزینی مقایسه/ادغام کنید.
4. تست‌ها را اجرا کنید:

   ```sh
   node --check assets/js/app.js
   node --test tests/*.test.cjs
   ```

5. برای فرستادن تغییرات به GitHub، فایل ZIP را معمولاً به‌عنوان سورس داخل مخزن commit نکنید؛ ابتدا آن را استخراج و فایل‌های موردنیاز را در مخزن بررسی و stage کنید. ZIP را فقط در صورت نیاز به‌عنوان release/download asset بارگذاری کنید.

## نتیجهٔ آزمون در workspace سازنده

`node --check assets/js/app.js` موفق و `node --test tests/*.test.cjs` با Playwright در دسترس **۲۴ از ۲۴** موفق بود. آزمون headless نشان داد drift marker با CSS جدید به صفر پیکسلی گرد شد؛ اما این آزمون جای آزمون فیزیکی روی گوشی/رایانهٔ مقصد را نمی‌گیرد و نتیجه‌ای دربارهٔ FPS واقعی تضمین نمی‌کند.

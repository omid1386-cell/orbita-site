# بستهٔ افزایشی ORBITA — گام دوم: برچسب خوشه‌ها

## روش اعمال
این ZIP را روی ریشهٔ پروژهٔ ORBITA استخراج کنید و فایل‌های هم‌مسیر را جایگزین کنید. مسیرها داخل ZIP از ریشهٔ پروژه شروع می‌شوند.

## محتویات
- `assets/js/app.js` — ساخت دسته‌ای تصویرهای برچسب خوشه با حفظ پیکسل‌های خروجی baseline.
- `index.html` — توکن cache مستقل برای `app.js`؛ توکن مشترک CSS و داده‌ها تغییر نکرده است.
- `tests/cluster_label_startup.test.cjs` — آزمون‌های رگرسیون برای atlas و cache token.

## بررسی پیشنهادی
از ریشهٔ پروژه اجرا کنید:

```sh
node --check assets/js/app.js
node --test tests/*.test.cjs
```

این بسته فایل CSS، داده‌ها، منطق pan/hover یا تغییرات تعاملی دیگری را شامل نمی‌شود. این ZIP تغییرات را روی GitHub اعمال یا commit نمی‌کند؛ ابتدا آن را استخراج کنید و سپس فایل‌های به‌روزشده را در مخزن قرار دهید.

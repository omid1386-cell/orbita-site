# بستهٔ اعمال بهینه‌سازی آغاز ORBITA

این ZIP **بستهٔ تغییرات افزایشی است، نه snapshot کامل سایت**. محتویات را در ریشهٔ مخزن موجود ORBITA استخراج کنید و مسیرها را حفظ کنید. فایل‌های موجودی که در فهرست ZIP هستند جایگزین می‌شوند؛ فایل‌های تازه به همان مسیر افزوده می‌شوند.

## فایل‌های منبعی که عمداً داخل ZIP نیستند

برای جلوگیری از بازنویسی داده‌های مخزن مقصد، این بسته شامل فایل‌های کامل منبع نیست:

- `data/companies.json` — منبع اصلی ۱۶۴ رکورد شرکت
- `assets/geo/countries.json` — هندسهٔ کامل کشورها؛ برای fallback دقیق کلیک لازم است
- دیگر داده‌های موجود پروژه، تصاویر، پوسته‌ها و وابستگی‌ها

این فایل‌ها را در مخزن نگه دارید. نسخه‌های آمادهٔ دسته‌بندی شرکت‌ها و هندسهٔ ساده‌شدهٔ نقشه داخل بسته هستند. فایل‌های شرکت از `data/companies.json` همین workspace (۱۶۴ رکورد) ساخته شده‌اند. اگر منبع شاخهٔ مقصد متفاوت است، پس از بررسی دادهٔ خودتان می‌توانید `python tools/split_companies_by_category.py` را اجرا کنید؛ این اسکریپت فایل منبع اصلی را تغییر نمی‌دهد و فقط فایل‌های مشتق‌شدهٔ دسته‌ها را بازسازی می‌کند.

`assets/geo/countries_simplified.json` نیز آمادهٔ استفاده است؛ بازسازی آن لازم نیست. اسکریپت اختیاری `tools/build_country_simplified.sh` فقط برای ساخت دوباره از `countries.json` است.

## بررسی پس از استخراج

از ریشهٔ مخزن اجرا کنید:

```sh
node --check assets/js/app.js
node --test tests/*.test.cjs
```

برای اجرای آزمون‌های مرورگریِ تعبیه‌شده در تست‌ها، محیط Node باید Playwright و Chromium داشته باشد؛ در غیر این صورت آن تست‌های مرورگر ممکن است skip شوند.

نسخهٔ cache در `index.html` برابر `20261103boot-opt1` است. بسته به معنیِ تغییرات فایل‌های فهرست‌شده محدود است؛ هیچ commit یا push در GitHub انجام نشده است.

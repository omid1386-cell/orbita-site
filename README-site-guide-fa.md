# راهنمای ORBITA — پیاده‌سازی محتوای تأییدشده، نسخهٔ ۳

راهنمای محلی و بازشوندهٔ ORBITA اکنون متن تأییدشدهٔ فارسی، انگلیسی و عربی را برای هشت موضوعِ خارج از نمای «پروژه‌های فضایی» نمایش می‌دهد. متن کوتاه موجود برای «پروژه‌های فضایی» عیناً حفظ شده و برای آن نمای، شرح تازه‌ای اضافه نشده است.

## ساختار UI

راهنما ۱۵ بخش بازشونده دارد: شروع سریع؛ نقشه و دسته‌ها؛ جست‌وجو؛ شناسنامهٔ کشور؛ متن کوتاه موجودِ پروژه‌های فضایی؛ پروندهٔ شرکت‌ها و سازمان‌ها؛ پایگاه پرتاب؛ فرود و بازیابی؛ نوار «پرتاب بعدی»؛ و بخش‌های عمومیِ اتصال، دامنه، منابع، وضعیت‌ها، محدودیت مکانی و واژه‌نامه.

متن جدید، معنی شمار کنار دسته‌ها، فیلتر و نتیجهٔ جست‌وجو، انواع پرونده، محدودیت داده و مختصات و تفاوت وضعیت‌ها را روشن می‌کند. یادداشت‌های قبلی دربارهٔ پوشش ۲۰ محل بازیابی، منبع و تازگی داده، تاریخ‌های متغیر و مرزهای جغرافیایی نیز حفظ شده‌اند.

## هزینه و محدودهٔ تغییر

- راهنما همچنان با درخواست کاربر باز می‌شود؛ تور اجباری، تصویر، وابستگی یا درخواست شبکهٔ تازه‌ای افزوده نشده است.
- هیچ map listener یا کار جدیدی روی رویدادهای نقشه اضافه نشده؛ منطق نقشه و فایل‌های داده تغییر نکرده‌اند.
- CSS فقط برای حفظ فاصله‌بندی و شکست‌خط پاراگراف‌های چندبخشی تنظیم شده است.
- نسخهٔ cache برنامه و CSS به‌روزرسانی شده‌اند؛ نسخهٔ مشترک داده دست‌نخورده است.

## آزمون

از ریشهٔ پروژه اجرا کنید:

```sh
node --check assets/js/app.js
node --test tests/*.test.cjs
```

در این نوبت، syntax check موفق و کل مجموعهٔ Node با ۳۶/۳۶ تست موفق بود. تست‌های مرورگریِ قبلی در این محیط قابل اجرا نبودند، چون Playwright نصب‌شده در دسترس نبود؛ پس آزمون مرورگر واقعی پس از این تغییر انجام نشده است.

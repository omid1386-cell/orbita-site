# راهنمای ORBITA — بازطراحی تعاملی Help

بخش Help همچنان با همان آیکون بالای صفحه باز می‌شود، اما حالا فقط یک فهرست متن نیست: جست‌وجوی داخلی، کارت‌های کارهای رایج، آیکون و پیش‌نمایش شماتیک برای بخش‌های نرم‌افزار، و پیشنهاد جایگزین هنگام پیدا نشدن نتیجه دارد.

## آنچه پیاده‌سازی شده

- جست‌وجوی محلی در عنوان‌ها، توضیح‌ها و واژه‌های هم‌معنی؛ بدون درخواست شبکه.
- ۱۷ موضوع بازشونده برای نقشه، دسته‌ها، جست‌وجو، کشورها، پروژه‌ها، پرونده‌های شرکت و پایگاه، فرود و بازیابی، دکمه‌ها، گزارش، منابع، وضعیت‌ها و محدودیت داده.
- آیکون‌های واقعی نشانگرهای دستهٔ نقشه در راهنما، همراه با تصویرک‌های داخلی برای بخش‌هایی که در نوار اصلی آیکون جدا ندارند.
- پیش‌نمایش شماتیک از دسته‌ها، فیلترهای پروژه، زبانه‌های پرونده و دکمه‌های بالای صفحه؛ این پیش‌نمایش‌ها دادهٔ زنده نیستند.
- کارت‌های «کارهای رایج» برای بازکردن راهنمای جست‌وجوی نقشه، پروژه‌ها و شمارش‌ها.
- اگر جست‌وجو نتیجه ندهد، چند موضوع نزدیک برای ادامه پیشنهاد می‌شود.
- دکمهٔ رفتن به جست‌وجوی نقشه، نمای پروژه‌ها یا فرم گزارش از خود راهنما.
- متن، عنوان‌ها و کنترل‌ها به فارسی، انگلیسی و عربی؛ چیدمان واکنش‌گرا و پشتیبانی صفحه‌کلید.
- توضیح پروژه‌ها بر اساس رفتار واقعی رابط: فیلترهای جدول با فهرست جداگانهٔ پرتاب‌های پیش‌رو یکی نیستند، زمان‌های جدول UTC است، و نشان‌های منبع به‌معنی کامل‌بودن جهانی نیستند.

## محدوده و امانت محتوا

راهنما قابلیت‌های قابل‌دسترسی در رابط فعلی را پوشش می‌دهد. نمای سه‌بعدی مدار چون زبانهٔ قابل‌دسترسی ندارد، معرفی نمی‌شود. پیش‌نمایش‌ها فقط برای شناسایی بخش‌اند و هیچ عدد یا رویداد زندهٔ ساختگی نمایش نمی‌دهند. هیچ وابستگی تصویری یا درخواست شبکه‌ای تازه‌ای به اپ اضافه نشده است.

## آزمون

از ریشهٔ پروژه اجرا کنید:

```sh
node --check assets/js/app.js
node --test tests/*.test.cjs
```

در این نوبت بررسی نحوی JavaScript موفق شد و مجموعهٔ آزمون Node با **۶۸ آزمون موفق و بدون شکست** تمام شد. آزمون خودکار مرورگر اجرا نشد؛ Playwright در محیط نصب نیست.

# راهنمای ZIP بارگذاری ORBITA — اصلاحات P1 و ممیزی آفریقا P2

## مبدأ و دامنه

- ZIP گزینشی است و فقط فایل‌های اصلاح‌شده/افزوده‌شده را در مسیرهای ریشهٔ مخزن دارد؛ کل workspace، فایل‌های پشتیبان، cache، کلید یا credential بسته‌بندی نشده‌اند.
- baseline واقعی تازه از `origin/main` گرفته شد. در زمان ساخت، مرجع روی commit `905a13ba31d09ac447061406bfabe5d862ce4382` بود؛ `HEAD` و `origin/main` برابر بودند.
- فایل گزارش‌گیری برنامه تغییر عملیاتی نکرده است. URL عمومی endpoint در `index.html` همان مقدار baseline است. آزمون گزارش فقط برای هم‌ترازشدن با مقدار واقعی baseline تصحیح شد.
- هیچ commit، push یا deploy انجام نشده است.

## تغییرات داخل بسته

- اصلاحات P1 و به‌روزرسانی‌های cache/testهای مرتبط با نقشه، زبان‌ها و تعاملات.
- داده‌های P1/P2 شرکت‌ها و سایت‌ها، به‌همراه چهار فایل category split بازتولیدشده از `data/companies.json`.
- ممیزی P2 و فهرست منابع تفکیک‌شده از دادهٔ اجرایی برنامه.
- آزمون‌های جدید `africa_priority1` و `africa_priority2`.
- یادداشت P1 موجود در `PATCH_README_fa.md` و اسکریپت ساخت tile که منبع فشرده را می‌خواند.

فایل‌های اصلی جدید برای ممیزی:

## روش استفاده

ZIP را در ریشهٔ checkout همان مخزن استخراج کنید و diff را بازبینی کنید. فایل‌های هم‌نام را جایگزین کنید؛ فایل‌های تازه را در مسیرهای موجود اضافه کنید. سپس آزمون‌ها را اجرا و commit را خودتان بسازید. این بسته خودش هیچ عملیات Git یا انتشار انجام نمی‌دهد.

# ORBITA — رسانه‌های سازمانی، نقطه ذخیره گام ۴

این بسته در مرحله تحقیق/تکمیل ۹۶ سازمان است؛ برای انتشار روی GitHub/Render نیست.

## تغییرات نسبت به بسته رسانه‌ای مراحل ۲ و ۳

- `data/media/catalog.v1.json` (۱۸ رسانه آماده نمایش / ۲ مورد مسدود)
- `docs/AGENCY_MEDIA_COVERAGE_96.csv` و `.json` (گزارش همه ۹۶ سازمان)
- `docs/AGENCY_MEDIA_SOURCES_20.csv` (دفترچه منبع و حقوق ۲۰ مورد)
- `tests/test_media_bank.py`, `tests/media-bank.test.cjs`, `tests/media-gallery.test.cjs` (آزمون‌های قبلی به‌روز شده‌اند؛ فرض خالی‌بودن بانک حذف شد)
- `tests/test_agency_media_stage4.py` و `tests/stage4-media-policy.test.cjs` (آزمون‌های جدید)

فایل‌های اجرایی گالری و رابط کاربری گام سوم در این مرحله تغییر نکرده‌اند. فایل ZIP تجمیعی صرفاً نسخه کاری موقت برای ادامه مراحل است؛ جایگزین نهایی فقط بعد از گام ۹ تهیه می‌شود.

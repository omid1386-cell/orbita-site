# راهنمای بسته اعتبارسنجی منبع زنده ORBITA

این بسته اصلاحی هنوز در مخزن اصلی یا وب‌سایت منتشر نشده است.

## نصب بر نسخه RC1

فایل‌های داخل `PATCH_FILES/` را با حفظ مسیرها در سورس کامل ORBITA جایگزین یا اضافه کنید. این فایل‌ها فقط جمع‌آوری داده، آزمون و گزارش را تغییر می‌دهند؛ فایل‌های `index.html`، `assets/css/app.css` و جاوااسکریپت رابط بدون تغییر هستند.

## آزمون با اتصال واقعی

```bash
python tools/validate_live_global_sources.py --launch-only --report launch_live_check.json
# اجرای فرودها در یک ساعت مجزا، به‌علت محدودیت ۱۵ درخواست در ساعت سرویس عمومی:
python tools/validate_live_global_sources.py --landing-only --report landing_live_check.json
```

این ابزار **هرگز** رکوردهای ذخیره‌شده سایت را نمی‌نویسد. برای درج خودکار داده بعد از تأیید، workflows اصلی جداگانه وجود دارند؛ پیش از فعال‌سازی آن‌ها باید نتایج واقعی آزمون بررسی شوند.

## معنی وضعیت‌ها

- `verified_full_source_window`: تمام صفحات پرتاب از سرویس دریافت و اعتبارسنجی شدند؛ به معنای پوشش تمام پرتاب‌های جهان مستقل از منبع نیست.
- `verified_partial_only`: روند دریافت فرودها قابل اجراست، ولی کامل‌بودن جهانی قابل تأیید نیست.
- `FAILED`: دریافت یا اعتبارسنجی انجام نشده؛ هیچ snapshot ای معتبرسازی نشده است.
- `source_only_probe_no_curated_merge`: آزمون منبع بدون فایل‌های legacy؛ به معنای بررسی نهایی بانک ادغام‌شده نیست.

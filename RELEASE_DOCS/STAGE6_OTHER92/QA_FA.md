- آزمون‌های Python: ۸۲ موفق، صفر ناموفق.
- آزمون‌های JavaScript/Node: ۳۷ موفق، صفر ناموفق.
- اعتبارسنج اختصاصی بانک رسانه: صفر خطا.
- تشخیص‌های قدیمی JSON Schema: ۱۱۶ پیش از دور سوم و ۱۱۶ پس از آن؛ افزایش نیافته‌اند.

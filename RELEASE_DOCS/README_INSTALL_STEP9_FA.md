# راهنمای نصب ایمن گام ۹ ORBITA

این نسخه **پیش از انتشار نهایی به بررسی محیط واقعی و همگام‌سازی زنده نیاز دارد**. هیچ‌یک از مراحل زیر در این گفت‌وگو روی GitHub/Render اجرا نشده است.

## پیش از نصب

۱. از آخرین وضعیت مخزن GitHub یک نسخه پشتیبان و یک شاخه مجزا مانند `orbita-upcoming-events-rc1` تهیه کنید.

۲. ZIP نامزد انتشار را استخراج کنید. باید ساختار پوشه‌ها از ریشه پروژه شامل `index.html`، `assets/`، `data/`، `tools/`، `tests/` و `.github/` حفظ شود.

۳. اگر شاخه آنلاین بعد از تهیه پارت‌های اصلی تغییر کرده است، پیش از جایگزینی فایل‌ها نسخه‌ها را تطبیق دهید. **جایگزینی کورکورانه فایل `index.html` یا `assets/css/app.css` ممنوع است.**

۴. روی رایانه با Python 3، از پوشه استخراج‌شده فرمان زیر را اجرا کنید (این فرمان هیچ فایلی را تغییر نمی‌دهد):

```bash
python RELEASE_DOCS/verify_release.py --target /path/to/original/ORBITA --mode before
```

## اعمال بسته

۵. فقط محتوای پوشه‌های اجرایی و فایل‌های درج‌شده در `RELEASE_DOCS/ORBITA_STEP9_MANIFEST.json` را با همان مسیر به شاخه آزمایشی منتقل کنید. فایل‌های `RELEASE_DOCS/` فقط مستندات انتشار هستند و برای اجرای وب‌سایت لازم نیستند.

۶. از تغییرات یک Commit مستقل بگیرید تا به‌آسانی بتوانید بازگردانی کنید.

۷. پس از اعمال در پروژه مقصد، دستور کنترل پس از نصب:

```bash
python RELEASE_DOCS/verify_release.py --target /path/to/original/ORBITA --mode after
```

(در این دستور، ابزار باید همچنان در پوشه استخراج‌شده بسته انتشار باقی بماند.)

## آزمون‌های الزامی

```bash
python -m unittest discover -s tools -p 'test_*.py' -q
node --test tests/step8-integration.test.cjs tests/upcoming-event-display.test.cjs tests/upcoming-landing-filters.test.cjs tests/upcoming-landing-ui.test.cjs tests/upcoming-launch-filters.test.cjs tests/upcoming-launch-ui.test.cjs tests/upcoming_global.test.cjs tests/launch-mission-ui-redesign.test.cjs
```

*توضیح:* ۴۸ خطای قدیمی در کل مجموعه `tests/*.test.cjs` وجود دارند و باید جداگانه با نسخه پایه مقایسه شوند.

## نخستین اجرا در محیط پیش‌نمایش

۸. قبل از انتشار عمومی، GitHub Actions دو workflow اضافه‌شده را روی شاخه مجاز اجرا و نتیجه دریافت اطلاعات زنده را بررسی کنید. تا آن زمان فایل‌های `data/upcoming_global.json` و `data/upcoming_global_landings.json` عمداً خالی‌اند و دارای وضعیت انتظار همگام‌سازی هستند.

۹. در نسخه پیش‌نمایش کنترل کنید: باز و بسته‌شدن هر دو پنل، فیلترهای ۷/۱۴/۳۰/۱۲۰ روز، چین + آمریکا، کشور اپراتور در برابر کشور پایگاه، زبان فارسی/انگلیسی/عربی، کارت‌ها در موبایل، نقشه و دیگر نشانگرها، فقدان نتیجه، شکست شبکه و نمایش زمان به‌روزرسانی.

۱۰. اگر در هر مرحله اختلال رخ داد، به‌جای بارگذاری مجدد همان فایل‌ها، ابتدا علت را رفع کنید. برای بازگشت، ترجیحاً Git revert و در صورت ضرورت ZIP بازگشت همراه بسته را به‌کار ببرید.

**تذکر:** این دستورالعمل، مجوزی برای انتشار خودکار نیست؛ فقط یک مسیر کنترل‌شده برای زمانی است که مالک پروژه تصمیم بگیرد.

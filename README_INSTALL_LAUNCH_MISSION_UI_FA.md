# راهنمای نصب بسته بازطراحی UI «پرتاب‌های پیش‌رو» ORBITA

## نصب بسته کوچک (اگر گام‌های ۱ تا ۶ قبلاً نصب شده‌اند)

۱. ترجیحاً در مخزن GitHub شاخه جدید بسازید و از فایل‌های فعلی نسخه پشتیبان بگیرید.
۲. **تنها** فایل `index.html` موجود در ریشه مخزن را با فایل هم‌نام داخل بسته جایگزین کنید.
۳. فایل `assets/js/upcoming-launch-browser.js` را جایگزین کنید.
۴. فایل **جدید** `assets/css/launch-mission-ui.css` را در پوشه `assets/css` بارگذاری کنید.
۵. تغییرات را Commit/Push کنید و پیش‌نمایش استقرار در Render را ببینید.
۶. ورود به نقشه را در تلفن همراه و دسکتاپ کنترل کنید: دکمه اختصاصی پایین چپ، بازکردن پنجره، چهار بازه، چین و آمریکا به‌صورت هم‌زمان، حذف کشور، جستجو و بستن پنجره.
۷. آزمون کنید که پنجره فرودهای پیش‌رو و شناسنامه‌های قبلی همان رفتار پیشین را دارند.

**فایل `assets/css/app.css` را تغییر ندهید.** قواعد جدید عمداً در یک فایل جدا هستند.

## بسته تجمیعی

اگر گام‌های ۱ تا ۶ را هنوز وارد مخزن نکرده‌اید، به‌جای بسته کوچک از ZIP تجمیعی «گام‌های ۱ تا ۶ + رابط جدید پرتاب‌ها» استفاده کنید. این ZIP شامل همه فایل‌های تغییرکرده مراحل قبلی نیز هست. هرگز هر دو بسته را هم‌زمان بدون بررسی اختلاف فایل‌ها وارد مخزن نکنید.

## کنترل داده‌های زنده

تغییر رابط، داده پرتاب واقعی تولید نمی‌کند. در GitHub Actions گردش‌کار `refresh-global-launches.yml` را اجرا کنید و بررسی کنید که `data/upcoming_global.json` از وضعیت `awaiting_first_successful_sync` خارج شده و تاریخ به‌روزرسانی تازه شده باشد. تا پیش از موفقیت آن، پیام «در انتظار همگام‌سازی» طبیعی است.

## برگشت به حالت قبل

برای حذف بازطراحی، دو فایل `index.html` و `assets/js/upcoming-launch-browser.js` را از کامیت قبلی بازیابی و فایل جدید `assets/css/launch-mission-ui.css` را حذف کنید؛ داده‌ها و دیگر بخش‌های اپلیکیشن نیازی به برگشت ندارند.

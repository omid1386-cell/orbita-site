بسته اصلاح رابط کاربری شناسنامه کشور ORBITA

فقط این سه فایل اجرایی را در ریشه مخزن خود جایگزین کنید:
- assets/js/app.js
- assets/css/app.css
- index.html

فایل data/sites.json عمداً در این بسته نیست و نباید با این اصلاح تغییر کند.

تغییرات:
1) برچسب نام ۱۴ دسته در کارت آماری سفید می‌شود.
2) رنگ اعداد و آیکون‌ها تغییر نمی‌کند؛ اعداد رنگ اختصاصی هر دسته را حفظ می‌کنند.
3) متن توضیحی انتهای کارت آماری از شناسنامه کشور حذف می‌شود.
4) شناسه کش CSS و JS افزایش یافته تا مرورگر نسخه جدید را دریافت کند.

پس از جایگزینی فایل‌ها:
1) تغییرات را در Git بررسی کنید.
2) اجرا کنید: node --check assets/js/app.js
3) اجرا کنید: node tests/country_profile_14_categories.test.cjs
4) Commit و Push کنید و پس از Deploy، سایت را با Hard Refresh باز کنید.

توجه: این بسته فقط اصلاح رابط کاربری است؛ هیچ داده‌ای از سایت یا شناسنامه‌ها را تغییر نمی‌دهد.

## ۲. روش تولید لینک نامزد

برای هر پنج مورد، یک URL از الگوی مشاهده‌شده در Google Earth Web ساخته شد:

`https://earth.google.com/web/@LAT,LON,0a,RANGE d,35y,0h,TILT t,0r`

این الگو در نمونه‌های URL نمای گوگل ارث دیده می‌شود و مختصات و پارامترهای دوربین را حمل می‌کند. با این حال، گوگل مستندات رسمی خود را برای اشتراک‌گذاری بر پایه «رفتن به Google Earth و کپی‌کردن URL نمای فعلی» ارائه می‌کند و این قالب تولیدشده را به‌عنوان API عمومی پایدار تضمین نمی‌کند. بنابراین این پیوندها صرفاً نامزد آزمایش‌اند؛ نباید هنوز در شناسنامه‌های عمومی رسپهر فعال شوند.

## ۴. نتیجه آزمون مرورگر واقعی در این محیط

برای هر پنج URL تلاش شد Chromium به صفحه Google Earth Web هدایت شود. هر پنج تلاش با خطای `net::ERR_BLOCKED_BY_ADMINISTRATOR` از سوی محیط اجرایی مسدود شد. ابزار وب نیز URLهای اختصاصی را به‌عنوان صفحات قابل دسترسی باز نکرد. این خطا از طرف محیط اجرای ماست و مدرکی بر رد یا خراب‌بودن لینک توسط گوگل نیست.

پس وضعیت صحیح نتیجه این است: «ساختار و مختصات تأیید آفلاین؛ بازشدن زنده نامشخص». هیچ‌یک از پنج URL به‌عنوان لینک تأییدشده ثبت نشده است.

## ۵. محدودیت مهم تجربه کاربر

این URLهای نامزد، دوربین Google Earth Web را روی مختصات و فاصله مشخص تنظیم می‌کنند. به‌تنهایی تضمین نمی‌کنند که یک Placemark با نام رسپهر یا کارت اطلاعات مکان نمایش داده شود. همچنین وجود تصویر ماهواره‌ای، مدل ساختمان سه‌بعدی یا Street View را اثبات نمی‌کند. این سه وضعیت باید جداگانه و پس از مشاهده واقعی ثبت شوند.

## ۶. تصمیم فنی

1. پنج لینک در فایل پایلوت جداگانه نگهداری می‌شوند؛ رجیستری عملیاتی ۴۲۰ مکان و UI تغییر نکرده است.
2. الگوی URL برای مرحله بعد فقط در صورت بازشدن واقعی و تطبیق مکان پذیرفته می‌شود.
3. اگر آزمون واقعی این الگو شکست بخورد، راه رسمی Google یعنی ساخت نمای موردنظر داخل Earth و کپی URL همان نمای مشخص، برای مکان‌های منتخب استفاده می‌شود.
4. هیچ لینک Earth، پانوراما یا مدل 3D بدون مدرک فعال نمی‌شود.
5. فایل‌های KML و پروژه جامع، مطابق تصمیم کاربر، در این گام استفاده یا توسعه داده نشده‌اند.

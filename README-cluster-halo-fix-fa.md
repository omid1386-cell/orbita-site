# اصلاح تعامل halo خوشه‌ها

این بسته فقط فایل‌های تغییرکرده را دارد؛ آن را با حفظ مسیرها روی پوشهٔ پروژهٔ Orbita باز کنید.

## تغییر
- halo بیرونی خوشه و برچسب آن به hit-test کلیک اضافه شده‌اند؛ کلیک روی بخش قابل‌دیدن halo فهرست خوشه را باز می‌کند.
- hover خوشه روی halo انجام می‌شود و hover کشورِ زیر خوشه را موقتاً کنار می‌زند؛ پس از خروج نشانگر، تعامل کشور دوباره فعال است.
- در هم‌پوشانی نقطه و خوشه، کلیک همچنان نقطه را در اولویت می‌گذارد.
- مسیر mousemove همچنان لایه‌محور و همگام‌شده با animation frame است؛ hit-test تکمیلی فقط هنگام کلیک یا خروج از لایه انجام می‌شود.
- فقط نسخهٔ کشِ فایل JavaScript به‌روز شده؛ نسخهٔ CSS و داده‌ها تغییر نکرده‌اند.

## فایل‌ها
- `assets/js/app.js`
- `index.html`
- `tests/cluster_label_startup.test.cjs`
- `tests/marker_halo_interaction.test.cjs` (آزمون جدید)

## آزمون
از ریشهٔ پروژه اجرا کنید:

```sh
node --check assets/js/app.js
node --test tests/*.test.cjs
```

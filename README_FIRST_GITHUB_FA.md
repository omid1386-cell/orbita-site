# رسپهر — بسته اصلاحات گام‌های اول تا هشتم برای GitHub

**این ZIP فقط تغییرات هشت گام است؛ کل اپلیکیشن در آن وجود ندارد.**

مبنا: سه پارت سورس اولیه‌ای که در همین گفتگو ارسال شد. آخرین نسخه هدف: گام هشتم، ۲۳ نوامبر ۲۰۲۶.

## محتویات

- پوشه `UPLOAD_TO_GITHUB/`: **دقیقاً 170 فایل** با مسیرهای مطابق ریشه مخزن
  - 161 فایل جدید
  - 9 فایل ویرایش‌شده که باید جایگزین نسخه قدیمی شوند
  - ۰ فایل حذف‌شده
- فایل `PATCH_MANIFEST.json`: فهرست تک‌تک فایل‌ها، وضعیت و هش SHA-256 نسخه قبلی و جدید
- فایل `PATCH_FILES.csv`: فهرست مختصر قابل بازکردن در Excel
- این راهنما بیرون از پوشه قابل آپلود است؛ خود راهنما لازم نیست در GitHub کپی شود.

## روش اعمال روی GitHub

۱. از مخزن GitHub فعلی نسخه پشتیبان یا یک شاخه جدید تهیه کنید.
۲. ابتدا مطمئن شوید مخزن فعلی از همان سورس سه‌پارتی استفاده می‌کند. در صورت تفاوت، **۹ فایل ویرایش‌شده** را با `PATCH_MANIFEST.json` مقایسه و تداخل‌ها را دستی رفع کنید.
۳. ZIP را استخراج کنید و **فقط محتویات داخل `UPLOAD_TO_GITHUB/`** را در ریشه پروژه (کنار `index.html`) کپی کنید. دقت کنید پوشه `UPLOAD_TO_GITHUB` را به‌عنوان یک پوشه داخل خود مخزن قرار ندهید.
۴. برای ۹ فایل هم‌نام، نسخه جدید جایگزین نسخه قدیمی شود؛ سایر فایل‌ها افزوده شوند. بقیه فایل‌های پروژه حفظ می‌شوند و نباید پاک شوند.
۵. بهتر است تغییرات ابتدا روی یک شاخه آزمایشی ثبت شود؛ سپس آزمون‌های پیشنهادی و مشاهده خروجی در Render انجام شود و فقط پس از تأیید، در شاخه اصلی ادغام کنید.

### نمونه اعمال روی نسخه محلی مخزن

```bash
# در مسیر مخزن محلی Git؛ پس از استخراج ZIP
cp -a /path/to/extracted/UPLOAD_TO_GITHUB/. ./
git status --short
git add -A
git commit -m "Integrate RASPEHR stages 1-8"
git push origin <your-test-branch>
```

**نکته:** دستورات بالا نمونه‌اند و در این گفتگو اجرا نشده‌اند؛ نام شاخه باید متناسب با مخزن خودتان جایگزین شود.

## بررسی‌های باقی‌مانده پیش از انتشار عمومی

- ۴۹ آزمون قدیمی سورس همچنان ناموفق‌اند و نیاز به تعیین تکلیف دارند.
- برخی لوگوهای محلی ارجاع شده در سورس وجود ندارند.
- داده‌های واقعی ارتفاعی DEM به‌صورت کامل محلی نشده‌اند.
- ۲۳ مختصات افزوده‌شده در گام هفتم **نقطه مرجع تقریبی با درجه عدم‌قطعیت** هستند، نه مختصات دقیق تأییدشده.
- آزمون نهایی روی گوشی فیزیکی و نسخه واقعی GitHub/Render انجام نشده است.

این بسته فقط برای آماده‌سازی تغییرات است؛ **هنوز هیچ فایلی در GitHub یا Render منتشر نشده است.**

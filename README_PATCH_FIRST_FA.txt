رسپهر V9 — وصله تجمیعی فقط تغییرات V2 تا V9
مبنا: آرشیو ۴ پارتی اولیه. این وصله را روی نسخه V8 یا روی GitHub بدون سنجش وضعیت فعلی اعمال نکنید.
این فایل انتشار عمومی نیست. ۴۷ آزمون نقشه دوبعدی هنوز شکست می‌خورند و WebGL واقعی آزمایش نشده است.
مسیر فایل‌های تغییرکرده با پیشوند orbita/ است. ۴۸ عکس پایگاه‌ها تغییر نکرده‌اند.

## انتخاب بسته

- اگر گام‌های ۱ تا ۷ را در سورس اصلی قرار داده‌ای، از ZIP مستقل گام هشتم استفاده کن.
- اگر هنوز هیچ‌یک از گام‌های قبلی را منتشر نکرده‌ای، از بسته **تجمیعی گام‌های ۱ تا ۸** استفاده کن. این بسته با پوشه اصلی اپ کامل یکی نیست؛ فقط مجموعه تغییرات افزوده‌شده در گام‌های ۱ تا ۸ است و باید روی همان سورس مبنا اعمال شود.
- قبل از اعمال هر بسته روی Git، از شاخه فعلی و `index.html` و داده‌ها نسخه پشتیبان تهیه کن.
